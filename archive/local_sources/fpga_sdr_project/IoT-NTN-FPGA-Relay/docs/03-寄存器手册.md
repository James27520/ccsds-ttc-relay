# 寄存器手册

基地址：**`0x43C00000`**（`XPAR_AXI_CTRL_0_BASEADDR`，改 BD 时未被改动，因此 BSP 不用重新生成）

窗口 64 字节，32 位字对齐。

## 完整寄存器表

| 偏移 | 名称 | 属性 | 位宽 | 说明 |
|---|---|---|---|---|
| `0x00` | `IDELAY_EN` | R/W | 7 | （厂商原有）IDELAY 使能 |
| `0x04` | `IDELAY_TAP` | R/W | 5 | （厂商原有）IDELAY 抽头，LVDS 眼图微调 |
| `0x08` | `DDS_PHASE_INC` | R/W | 12 | （厂商原有）DDS 相位增量，DDS 断开后闲置 |
| `0x0C` | `PHY_MODE` | R/W | 1 | （厂商原有）1 = 1R1T，0 = 2R2T |
| **`0x10`** | **`RELAY_MODE`** | R/W | 2 | **0=旁路 1=转发 2=静音 3=仅上变频** |
| **`0x14`** | **`RELAY_DDC_FREQ`** | R/W | 32 | **DDC NCO 相位增量** |
| **`0x18`** | **`RELAY_DUC_FREQ`** | R/W | 32 | **DUC NCO 相位增量** |
| **`0x1C`** | **`RELAY_GAIN`** | R/W | 12 | **数字增益，Q1.11（`0x800` = 1.0）** |
| | `RELAY_DC_EN` | R/W | 1 | bit 12：隔直使能（仅转发模式有效） |
| **`0x20`** | **`STATUS_SAMPLE_CNT`** | RO | 32 | **已接收的通道 1 样点数** |
| **`0x24`** | **`STATUS_CLIP_CNT`** | RO | 32 | **饱和事件累计数** |
| **`0x28`** | **`STATUS_OUT_CNT`** | RO | 32 | **已发出的 `dac_valid` 脉冲数** |
| `0x2C`–`0x3C` | — | — | — | 保留 |

> **加粗**为本次新增。厂商原有寄存器全部保持不变，所以旧的应用代码仍能正常运行。

## 频率字

```
freq_word = round( 频偏Hz / fs × 2³² )        （32 位，二补码）
净变换量   = (RELAY_DUC_FREQ − RELAY_DDC_FREQ) / 2³² × fs
```

fs = 30.72 MHz 时的常用值：

| 频偏 | 频率字 (hex) | 十进制 |
|---|---|---|
| +10 kHz | `0x000D1B71` | 859505 |
| +100 kHz | `0x00D55555` | 13981013 |
| +480 kHz | `0x04000000` | 67108864 |
| 0 | `0x00000000` | 0 |
| −100 kHz | `0xFF2AAAAB` | 4280986283 |
| −480 kHz | `0xFC000000` | 4227858432 |

> ⚠️ **负值必须用二补码写入**。`relay_reg.h` 里的 `relay_freq_word()` 已修正——早期版本负数 double 直接转无符号是 UB，ARM 上会静默变成 `0`，所有负频偏失效。

## 数字增益

Q1.11 定点，`0x800` = 1.0：

| 值 | 增益 |
|---|---|
| `0x000` | 0 |
| `0x400` | 0.5 |
| `0x800` | 1.0（推荐默认） |
| `0xC00` | 1.5 |
| `0xFFF` | ≈ 2.0（超过输入满幅就会削顶） |

**注意**：这是 PL 内部的复乘系数，范围只有 0~2。**真正决定灵敏度的主增益是 AD9361 的 RX 增益（0~76 dB）**，通过 UART 命令 `rxgain` 设置。数字增益只用来做小范围补偿，例如补 DDC/DUC 级联那 `0.9995² ≈ 0.1%` 的固有损耗，设 `0x801` 即可。

## 状态计数器的读法

三个计数器都来自 `relay_counter_snap`：源域每 **4096 个样点**把值锁存到影子寄存器并翻转一个标志，AXI 侧检测到标志变化后整体拷贝。

- **好处**：读到的永远是自洽快照，不会撕裂
- **代价**：最大陈旧度 4096 样点 ≈ **133 µs** @30.72 MSPS（可忽略）

**判定方法：**

| 观察 | 结论 |
|---|---|
| `ΔSAMPLE_CNT == ΔOUT_CNT` | **零丢样** |
| `ΔSAMPLE_CNT != ΔOUT_CNT` | 丢样，检查 relay_mode 与时钟 |
| `ΔSAMPLE_CNT == 0` | 没有 ADC 数据（PHY 模式或 RX 输入问题） |
| `ΔOUT_CNT == 0` 但采样在涨 | relay_mode 可能是 2（静音） |
| `SAMPLE_CNT − OUT_CNT` | 恒定 = 流水线深度 + 计数对齐，**不是丢样** |
| `ΔCLIP_CNT > 0` | 增益过高，减小 `rxgain` 或数字增益 |

## 从 PS 访问

```c
#include "relay_reg.h"

relay_set_mode(RELAY_MODE_RELAY);
relay_set_ddc_freq(0);
relay_set_duc_freq(relay_freq_word(100000, 30720000));   /* +100 kHz */
relay_set_gain(RELAY_GAIN_UNITY, 0);

u32 n_in  = relay_get_sample_cnt();
u32 n_out = relay_get_out_cnt();
u32 n_clip= relay_get_clip_cnt();
```

## 从 PC 访问（UART 命令行）

```
mode 1              设置转发模式
off 100000          设置 DUC 频偏 +100 kHz
off -100000         设置 DUC 频偏 −100 kHz
xoff 0              设置 DDC 频偏
gain 0x800          数字增益
dc 1                开隔直
rxgain 30           AD9361 RX 增益 30 dB
txatt 20            TX 衰减 20 dB
lo 900 1000         收发本振
status              读一行完整状态
```

完整命令列表见 `docs/04-上机测试步骤.md`。

## 从 JTAG 访问

PL 地址区被 hw_server 挡住（`PL AXI slave ports access is not allowed`），改读 DDR 里的状态信箱：

```tcl
xsct> connect
xsct> targets -set -filter {name =~ "ARM*#0"}
xsct> stop
xsct> mrd 0x003F0000 8
xsct> con
```

| 地址 | 内容 |
|---|---|
| `0x003F0000` | magic `0x524C4159`（'RLAY'） |
| `0x003F0004` | 收样点 |
| `0x003F0008` | 发样点 |
| `0x003F000C` | 饱和计数 |
| `0x003F0010` | 健康检查 rc |
| `0x003F0014` | 心跳（证明 CPU 在跑） |
