# 上机测试程序

`test_relay_board.py` —— 对已上电自启动的板子做一轮完整验证。

```bash
python test_relay_board.py                  # 自动检测串口
python test_relay_board.py COM5             # 指定串口
python test_relay_board.py COM5 --loss 10   # 零丢样测试跑 10 秒
python test_relay_board.py --list           # 只列串口
```

**不需要任何仪器**，跑完约 18 秒。实测结果：**39 项通过 / 0 项失败 / 1 项需仪器**。

## 2. ⚠️ 测试中发现的两个真实特性

这两个都不是缺陷，但**写监测代码时必须处理**。

### 2.1 状态行的读竞态（差值恰好 4096）

**现象**：偶尔出现 `Δin` 与 `Δout` 相差**恰好 4096**。

**原因**：固件构造 `status` 行时是**逐个读 AXI 寄存器**的（先读收样点、再读发样点）。
而 PL 里三个计数器每 **4096 个样点**做一次一致性快照。如果快照更新正好落在这两次
AXI 读之间，读到的两个数就来自**不同快照**，差值恰好是一个快照周期。

**这是测量竞态，不是丢样。**

**处理**（已实现在 `RelayLink.measure()`）：

```python
if din == dout:                       return ...   # 一致
if (din - dout) % 4096 != 0:          return ...   # 不是整周期 -> 真丢样，不重测
# 否则是竞态 -> 重测（最多 4 次）
```

**判据要点**：**真丢样的差值不会是 4096 的整数倍**；是整数倍就重测。

> 更好的修法是在固件里把三个计数器一次读全（对齐 toggle 版本号），
> 但那需要重新编译并更新 SD 卡上的 `relay.elf`，当前用重测规避足够。

### 2.2 32 位计数器约 140 秒回绕一次

**现象**：`T8` 里出现 `4291309583 -> 56827919`。

**原因**：`in` / `out` / `clip` 都是 **32 位**，30.72 MSPS 下：

```
2^32 / 30.72e6 ≈ 139.8 秒 ≈ 2 分 20 秒
```

**必须用模运算求增量：**

```python
def delta(a, b):
    return (b - a) & 0xFFFFFFFF
```

**对 RK3588 监测代码的影响**：

- 不能用 `if n_in > last_in` 判断"还在跑"——回绕时会误判
- 计算速率要用 `(b - a) & 0xFFFFFFFF`
- 长时间统计要自己维护 64 位累加器
- 累计饱和率 `clip / in` 在回绕后失去意义，应改用测量窗口内的 `Δclip / Δin`

## 3. 需要 CMU200 才能验证的项

程序跑完会打印这份清单。软件只能确认**寄存器写对了**，**射频上到底发生了什么必须用仪器看**：

| # | 操作 | 预期 | 证明什么 |
|---|---|---|---|
| 1 | CMU200 RF2 出 900.100 MHz → SDR RX1；SDR TX1 经 ≥20 dB 衰减器 → CMU200 RF1 | 在 **1000.100 MHz** 看到信号 | 转发通路打通 |
| 2 | 设 DUC 频偏 **+100 kHz** | 输出移到 **1000.200 MHz** | ★ **PL 在数字域做了上变频**，不是靠 TX_LO 搬频 |
| 3 | 设 DDC 频偏 +100 kHz、DUC=0 | 输出反向移动 | 下变频独立可控 |
| 4 | 模式切"静音" | 输出消失 | 安全静音有效 |
| 5 | 看 TX_LO 正频点有无杂散单音 | 有则打开"隔直" | 本振泄漏被抑制 |
| 6 | 看信号质量 | 必要时调 RX 增益 / TX 衰减 | 增益链路正确 |

> ⚠️ **第 2 步是整个演示的核心证据。** 只做第 1 步（DDC=DUC=0）时 PL 在功能上等价于直通，
> 输出频率完全由 `TX_LO + (输入 − RX_LO)` 决定，**不能用来声称"PL 做了数字变频"**。

## 4. 接线与安全

```
CMU200 RF2 OUT ──► SDR RX1
SDR TX1 ──► [≥20 dB 衰减器] ──► CMU200 RF1 IN
```

**首次上电务必先量 TX 实际输出功率再接入仪器。** 原厂代码里 TX 衰减参数单位写错
（`70` mdB = 0.07 dB ≈ 满功率），本仓库已改为 30 dB，但仍建议实测确认。
