## 2. 为什么是"三平面"

核心原则：**实时性要求不同的东西，物理上分开。**

| 平面 | 位置 | 实时性 | 传什么 |
|---|---|---|---|
| 数据面 | PL 内闭环 | **硬实时、确定性** | 样点流，永不离开芯片 |
| 控制面 | PS 裸机 + AXI-Lite | 非实时 | 参数（写）、状态（读） |

**数据面内不存在任何跨时钟域** —— `ad9361_phy` 的 ADC/DAC 接口与两个 NCO 全都在 `data_clk` 上。只有控制字与状态计数器需要跨域。

## 3. 时钟域

| 时钟 | 频率 | 用途 |
|---|---|---|
| `rx_clk` (`data_clk`) | **122.88 MHz** | 数据面全部逻辑。2R2T 下 = 4 × 30.72 MSPS |
| `clk_fpga_0` | 100 MHz | PS FCLK_CLK0，AXI-Lite |
| `clk_fpga_1` | 200 MHz | IDELAYCTRL 参考 |
| `clk_out1_design_1_clk_wiz_0_1` | 100 MHz | ILA |
| `sys_clk` | 40 MHz | dbg_hub |

**跨域处理（全部显式同步，并在 XDC 里声明为异步域）：**

| 路径 | 机制 | 文件 |
|---|---|---|
| `clk_fpga_0` → `rx_clk` | 2-FF 同步器 + 连续 4 拍不变才接受 | `relay_cdc_word` |
| `rx_clk` → `clk_fpga_0` | 影子寄存器 + 翻转握手（4096 样点一次） | `relay_counter_snap` |
| 复位 | 异步置位、同步释放 | `relay_reset_sync` |

> **为什么多 bit 控制字不用握手**：这些字（模式/频率/增益）每秒只被软件改几次。2-FF 单独用可能采到跳变中途的撕裂值；要求"连续 N 拍不变才接受"使撕裂捕获在实践中不可能发生，运行时零开销，且写入侧不需要任何协议。

## 4. 数据面细节

### 4.1 频率关系

```
输出频率 = TX_LO + (输入频率 − RX_LO) + (DUC_FREQ − DDC_FREQ) / 2³² × fs

频率字 = round( 频偏 / fs × 2³² )
```

`relay_dq` 的净变换量 = `(duc_freq − ddc_freq) / 2³² × fs`。

**32 位相位累加器**给出 fs/2³² 的分辨率（30.72 MSPS 下约 **7.2 mHz**）——远超 RF LO 的调谐精度，这正是 PL 数字变频相对 PLL 的核心优势。

### 4.2 四种工作模式

| 值 | 模式 | 行为 |
|---|---|---|
| 0 | `BYPASS` | DAC ← ADC 原始数据（延迟 9 级） |
| 1 | `RELAY` | DDC → 隔直 → DUC → 增益 |
| 2 | `MUTE` | 输出置零（安全态，也是复位默认） |
| 3 | `DUC_ONLY` | DUC → 增益（DDC 与隔直旁路，纯搬频） |

**所有模式延迟完全一致（9 级 = 10 个 `data_clk` 周期）**，所以软件切换模式不会改变 DAC 时序。

> 2R2T 下 `data_clk = 4 × 每通道采样率`，30.72 MSPS → **122.88 MHz**，因此 10 个周期 ≈ **81 ns**。
> 不要把它换算成「9 个采样周期」——那是把 `data_clk` 和采样率混为一谈。

### 4.3 定点与位宽

| 位置 | 位宽 | 定标 |
|---|---|---|
| I/Q 数据 | 12 bit 有符号 | 满幅 ±2047 |
| NCO cos/sin | 12 bit 有符号 | 满幅 ±2047 ≈ ±1.0 |
| 复乘乘积 | 24 bit 有符号 | 12×12，显式符号扩展到 25 bit 再相加 |
| 复乘输出 | 12 bit 有符号 | 归一化 `>>>11`（单位幅度 NCO ↔ 单位增益） |
| 隔直均值 | 17 bit 有符号 | 泄漏积分器，时间常数 2¹² 样点（30.72 MSPS 下约 1.2 kHz） |
| 数字增益 | 12 bit 无符号 | Q1.11，`0x800` = 1.0 |
| 增益输出 | 12 bit 有符号 | 饱和钳位并置饱和标志 |

**相位截断 12 bit 对应最坏杂散约 −72 dBc**，与 12 bit 数据通路的量化底噪匹配。
**复乘累加器 25 bit** 相对最坏情况（2 × 2047 × 2047 = 8,380,418）仍有余量，中间不会溢出。

### 4.4 隔直器（无乘法器）

```
mean[n] = mean[n-1] + (x[n] − mean[n-1]) >>> K      K = 12
y[n]    = x[n] − mean[n-1]
```

只用加法和移位，**0 个 DSP48**。用于消除 AD9361 RX 本振泄漏在基带产生的直流分量——否则它会被搬到 TX 中心频点，形成不该有的杂散单音。

### 4.5 流水线对齐（9 级）

样点 s 在 `in_valid` 生效的 t 拍进入：

| 节拍 | valid | 内容 |
|---|---|---|
| t | `in_valid` | 样点呈现；两个 NCO 推进 |
| t+1 | `vld[0]` | `s_i/s_q` = 样点 s |
| t+2 | `vld[1]` | NCO cos/sin(s)；DDC 乘积寄存 |
| t+3 | `vld[2]` | DDC 第二级 |
| t+4 | `vld[3]` | DDC 输出 |
| t+5 | `vld[4]` | 旁路选择，寄存 |
| t+6 | `vld[5]` | 隔直（差值寄存） |
| t+7 | `vld[6]` | DUC 乘积；n4 = NCO(s) |
| t+8 | `vld[7]` | DUC 第二级 |
| t+9 | `vld[8]` | 增益 → `out_valid` |

**每级寄存器由各自的 valid 位限定**，所以稀疏 valid（2R2T 每 4 拍一个样点）不会样点碰撞。

### 4.6 为什么流水线这么深

关键路径原本是：

```
ROM → 象限取反(CARRY4×3) → LUT → DSP48 乘 → DSP 级联加 → 饱和比较 → 寄存器
```

**12.03 ns**（要求 8.138 ns）。拆成三段后每段都有充足余量：

1. `relay_cmix` 两级：`FF → DSP48(MREG/PREG) → FF` 与 `FF → 25bit 进位加 → 移位 → 比较饱和 → FF`
2. `relay_nco` 输出寄存：切断 `BRAM → 取反 → DSP`
3. 旁路 mux 结果寄存：切断宽扇出控制网进入隔直的进位链

另外 `mode` 是来自 CDC 的慢速字，扇出 189、布线 2.088 ns。**先解码成局部寄存器再用作 mux 选择**，避免它成为长路径起点。

## 5. PS 侧

**只做三件事：**

1. **上电配置**：`ad9361_init()` → 关 BIST → 写转发参数 → 健康自检
2. **UART 命令行**：`relay_cli.h`，约 40 条命令（见 `docs/04-上机测试步骤.md`）
3. **JTAG 状态信箱**：DDR `0x003F0000`，主循环刷新

**明确不做：** 不搬运样点、不做 DSP、不做解调译码。

### 5.1 三个必须关掉/修正的东西

| 项 | 原值 | 问题 | 修正 |
|---|---|---|---|
| AD9361 BIST | `0x3F4 = 0x03` | = BIST 使能 + TX 注入点 + 单音模式，**芯片内部单音会取代接口送来的 DAC 数据** | 注释掉 |
| TX 衰减 | `70` | 驱动文档说明单位是 **mdB**，70 mdB = 0.07 dB ≈ 满功率 | 改为 `30000`（30 dB） |
| 测试频点 | 2400/2400 MHz | 收发同频，FDD 下易自激 | 改为 900/1000 MHz |

## 6. 资源

| 资源 | 占用 | 总量 | 占比 |
|---|---|---|---|
| DSP48E1 | **20** | 80 | 25.0 % |
| Block RAM Tile | 4.5 | 60 | 7.5 % |
| Slice Registers | 5229 | 35200 | 14.9 % |
| Slice LUTs | 3084 | 17600 | 17.5 % |
| Bonded IOB | 45 | 100 | 45.0 % |

**时序：WNS +0.540 ns，WHS +0.016 ns，0 失败终点 / 13030。**

DSP 占用与设计时的逐项估算完全一致：

```
DDC NCO 复混频   4
DC 阻断          0   ← 泄漏积分器
DUC NCO 复混频   4
数字增益         2
─────────────  ────
单通道          10  × 2 通道 = 20
```

剩余 60 个 DSP48 足够再扩展 **2~3 个窄带信道**（CIC 抽取 + 信道 FIR）。
