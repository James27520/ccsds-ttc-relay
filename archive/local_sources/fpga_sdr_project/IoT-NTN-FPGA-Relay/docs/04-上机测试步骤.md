# 上机测试步骤

## 0. 前置条件

| 项 | 要求 |
|---|---|
| 硬件 | LDSDR 开发板（Zynq XC7Z010 + AD9361），JTAG + USB 串口已连 |
| 软件 | Vivado / SDK 2018.3；PC 端 Python 3.8+（GUI 无需第三方库） |
| 码流 | 已构建的 `ad9361_top.bit` 与 `9361.elf` |
| 仪器 | CMU200（或任意信号源 + 频谱仪） |

> ⚠️ **开发期间请拔掉 SD 卡。** 只要卡插着，板子一断电/复位就会从卡启动原厂 Pluto Linux，JTAG 下载的转发器消失。`ps7_init` 会把 PS 和 DDR 都初始化好，不依赖任何启动介质。

## 1. 下载

```bash
xsct <repo>/scripts/program_device.tcl
```

脚本依次做六件事：

| 步 | 动作 | 说明 |
|---|---|---|
| 1 | `connect` | 连接 hw_server |
| 2 | `rst -system` | 复位 PS + PL |
| 3 | `ps7_init` | **必须**。否则 `dow` 报 `Cannot access DDR: the controller is held in reset` |
| 4 | `fpga -file` | 下载 PL 码流 |
| 5 | `ps7_post_config` | 使能 PS/PL 电平转换器 |
| 6 | `dow` + `con` | 下载 ELF 并运行 |

成功后串口应打印：

```
===== PL relay enabled =====
  RX_LO       = 900000000 Hz
  TX_LO       = 1000000000 Hz
  sample_rate = 30720000 Hz
  TX atten    = 30000 mdB (30 dB)
  relay mode  = RELAY, DDC=0, DUC=0, gain=1.0
  status      : in=... out=... clip=... rc=0
  relay OK
============================
```

**`rc` 的含义：**

| rc | 含义 | 处理 |
|---|---|---|
| 0 | 正常 | — |
| −1 | 没有 ADC 数据 | 检查 AD9361 RX 输入、PHY 模式、采样率 |
| −2 | ADC 在跑但没有 DAC 输出 | 检查 `RELAY_MODE` |

## 2. 打开监控界面

```bash
python <repo>/tools/relay_gui.py            # 自动检测串口
python <repo>/tools/relay_gui.py COM5       # 指定串口
python <repo>/tools/relay_gui.py --list     # 只列出串口
```

**界面布局：**

- **连接栏**：串口选择、刷新、自动检测、连接/断开
- **转发状态**：收样点 / 发样点 / 实测速率 / 收发差值 / 饱和计数 / 饱和率 / **丢样检测** / 健康
- **当前参数**：工作模式、DUC 频偏 Hz、DDC 频偏 Hz、数字增益、隔直、RX LO、TX LO、RX 增益、**TX 衰减** —— 全部可直接修改，回车或点「应用」下发
- **快捷频偏**：`0 / +10k / +50k / +100k / +480k / −100k` Hz 一键设置
- **日志**：板子回什么显示什么；底部命令行可发任意命令

**丢样检测是自动的**：每次轮询比较 `Δout` 是否等于 `Δin`，不等就把"丢样"标红。

> 如果连上后参数栏一直空白、日志出现 `pluto login:` 之类字样，说明**板子上跑的不是转发程序**（多半是从 SD 卡启动了原厂 Linux）。GUI 会在 1.8 秒后给出明确提示。

## 3. 参数设置

### 3.1 核心公式

```
输出频率 = TX_LO + (输入频率 − RX_LO) + (DUC_FREQ − DDC_FREQ) / 2³² × fs
```

### 3.2 推荐起始值

| 参数 | 起始值 | 范围 | 说明 |
|---|---|---|---|
| 工作模式 | `转发 relay` | 旁路/转发/静音/仅上变频 | |
| DUC 频偏 Hz | `0` | ±15.36 MHz | 0 = 不搬频 |
| DDC 频偏 Hz | `0` | ±15.36 MHz | |
| 数字增益 | `0x800` | `0x000`~`0xFFF` | Q1.11 |
| 隔直 | `0` | 0/1 | 有本振泄漏杂散时改 1 |
| RX LO MHz | `900` | 70~6000 | **与信号源频点对齐** |
| TX LO MHz | `1000` | 70~6000 | |
| RX 增益 dB | `0` 起步往上加 | 0~76 | **主增益** |
| TX 衰减 dB | `30` | 0~89 | **越大输出越小**，0 = 满功率 |

### 3.3 调参顺序

1. **对齐频率**：RX LO = 信号源频点，TX LO = 目标频段中心 → 点「应用」
2. **找信号**：频谱仪在 `TX_LO + (源频率 − RX_LO)` 处找。
   找不到 → **一次加 10 dB RX 增益**，或**减小 TX 衰减**
3. **看质量**：界面「饱和率」应接近 0。超过 0.1% → 减 RX 增益或数字增益
4. **验证数字变频**：点「+100 kHz」，频谱仪读数应**跟着移 100 kHz**

## 4. CMU200 端到端测试

### 4.1 接线

```
CMU200 RF2 OUT ──► SDR RX1
SDR TX1 ──► [≥20 dB 衰减器] ──► CMU200 RF1 IN
```

> ⚠️ 首次上电**务必先量 TX 实际输出功率**。原厂代码里 TX 衰减写的是 `70`（mdB，即 0.07 dB ≈ 满功率），本仓库已改为 30 dB，但仍建议实测确认后再接仪器。

### 4.2 步骤

| 步 | 操作 | 预期现象 | 判据 |
|---|---|---|---|
| 1 | CMU200 RF2 输出 900.100 MHz 单音 | ILA 能抓到 I/Q 波形 | I/Q 呈正交正弦 |
| 2 | 读界面状态 | `rc=0`，丢样显示"无" | 转发链路正常 |
| 3 | CMU200 RF1 在 **1000.100 MHz** 找信号 | 看到转发出来的单音 | 频率一致、幅度稳定 |
| 4 | 点 **「+100 kHz」** | 输出移到 **1000.200 MHz** | **核心证据：PL 在数字域完成上下变频** |
| 5 | 点 **「−100 kHz」** | 输出反向移动 | 双向变频都正常 |
| 6 | 点「净变换归零」 | 回到 1000.100 MHz | DDC/DUC 独立可控 |
| 7 | 点「静音」 | 输出消失 | 安全静音通路有效 |
| 8 | 读「饱和计数」 | 应保持不增长 | |

**第 4 步是整个演示的核心**：它证明变频发生在 PL 的数字域，而不是靠 TX_LO 硬件搬频。建议把第 3、4、7 步的频谱截图作为报告证据。

## 5. 不开 GUI 时的观测手段

### 5.1 串口命令行

任意串口终端，**115200 8N1**（PS UART1 @ `0xE0001000`）：

```
help                命令列表
status              一行完整状态
auto <0|1>          周期上报开关

mode <0..3>         0=旁路 1=转发 2=静音 3=仅上变频
ddc <val>           DDC 频率字（支持 0x 十六进制）
duc <val>           DUC 频率字
off <hz>            按 Hz 设 DUC 频偏（用当前 fs 换算）
xoff <hz>           按 Hz 设 DDC 频偏
gain <0..0xFFF>     数字增益
dc <0|1>            隔直开关

rxgain <db>         AD9361 RX 增益 0~76
txatt <db>          TX 衰减 0~89
lo <rxMHz> <txMHz>  改收发本振
rate <MSPS>         改采样率（见下方警告）
```

`status` 返回格式（便于脚本解析）：

```
STAT mode=1 ddc=00000000 duc=04000000 gain=800 dc=0 rxgain=0 txatt=30
     rxlo=900 txlo=1000 fs=30720000 in=3134275583 out=3134275578 clip=178051 rc=0
```

> ⚠️ **`rate` 命令的警告**：`DATA_CLK` 周期由采样率推导
> `period_ns = 4000 / sample_rate_in_MSPS`（2R2T 模式）
> 只改软件而不重新综合匹配的约束，可能破坏 AD9361 的 LVDS 接口。

### 5.2 JTAG 状态信箱

不占用串口，也不需要 CPU 停在断点：

```tcl
xsct> connect
xsct> targets -set -filter {name =~ "ARM*#0"}
xsct> stop
xsct> mrd 0x003F0000 8
xsct> con
```

| 地址 | 内容 |
|---|---|
| `0x003F0000` | magic `0x524C4159` |
| `0x003F0004` | 收样点 |
| `0x003F0008` | 发样点 |
| `0x003F000C` | 饱和计数 |
| `0x003F0010` | 健康 rc |
| `0x003F0014` | 心跳 |

仓库里的 `scripts/verify_relay.tcl` 会自动做"运行 → 停止 → 读 → 恢复"三轮，并计算 Δin / Δout：

```
read 1 : magic=0x524C4159  in=1186590702  out=1186590714  clip=275615  rc=0
read 2 : magic=0x524C4159  in=1264861166  out=1264861178  clip=275615  rc=0
         Δin = 78270464   Δout = 78270464      ← 零丢样
```

### 5.3 Windows 自带工具

GUI 内置了纯 ctypes 的 Win32 串口实现，不依赖 pyserial。若想用别的方式，任何串口终端（PuTTY / MobaXterm / Tera Term）都可以，参数 **115200 8N1**。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 串口出现 `pluto login:` | 板子从 SD 卡启动了原厂 Linux | 重新下载；开发期拔掉 SD 卡 |
| `dow` 报 DDR 在复位 | 缺 `ps7_init` | 用仓库里的 `program_device.tcl` |
| 串口打开报 err 5 | 被别的程序占用 | 关掉其他串口终端 |
| 完全收不到信号 | TX 衰减过大 / RX 增益过小 | 界面里调 |
| 有信号但频率不对 | RX LO / TX LO 与信号源没对齐 | 检查公式 |
| 中心频点有杂散单音 | AD9361 RX 本振泄漏 | 「隔直」设 1 |
| 饱和率偏高 | RX 增益或数字增益过大 | 逐步调小 |
| 负频偏无效果（回 `duc=00000000`） | 早期版本的 UB bug | 用 `relay_reg.h` 里的修正版 |
| ILA 波形混叠 | ILA 时钟与 data_clk 不同源 | 需把 `ila_0/clk` 改接 `ad9361_phy_0/data_clk` |
