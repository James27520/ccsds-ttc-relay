# 遥控链路协议（信号发生器 → 新遥控板，SMA 电缆）

> 传输内容：**只有两个频率** —— 接收频段（rx_lo）和转发频段（tx_lo），单位 MHz。
> 链路：旧遥控板（信号发生器） `SMA + 衰减器` ADDA 板（新遥控板，ADC 接收）。
> 本文是双方实现的**唯一依据**，任何改动都要同步更新末尾的"变更记录"。

---

## 一、协议总览（五层）

| 层 | 内容 |
|---|---|
| **物理层** | SMA 电缆 + 衰减器；载波 100.5 MHz；带宽 135 kHz |
| **调制层** | BPSK + SRRC（β=0.35），100 kSPS |
| **编码层** | CCSDS 随机化 + 卷积编码 1/2（K=7）+ ASM 同步字 |
| **帧层** | 8 字节 body：`ver + rx_lo + tx_lo + seq + CRC16` |
| **应用层** | 收到后立即用 `lo <rx> <tx>` 设置转发板 |

---

## 二、物理层

| 参数 | 值 | 说明 |
|---|---|---|
| **载波中心** | **100.5 MHz** | = TX LO 100 MHz + 基带偏移 +0.5 MHz |
| 为什么偏移 0.5 MHz | — | 避开 AD9361 本振泄漏（DC 尖峰会落在信号中间） |
| 占用带宽 | **135 kHz** | 100 kSPS × (1+0.35) |
| 发射电平 | TX 衰减 30 dB + 外部 **50 dB** 衰减器 | ADDA ADC 输入约 −60 dBm，安全 |
| 连接 | SMA 电缆（不用天线） | 100 MHz 属 FM 广播频段，禁止辐射 |
| 采样率（发射侧） | 2.5 MSPS | 每符号 25 点 |

**⚠️ 若以后改中频，必须同时改本表、`link_spec.json`、ADDA 侧混叠计算。**

## 三、调制层

```
比特 → 符号：  bit 0 → +1      bit 1 → −1      （BPSK）
成形：        SRRC，β = 0.35，span = 8 符号
上采样：      1:25 零插值（2.5 MSPS / 100 kSPS）
载波：        +500 kHz（复基带），最终落在 100.5 MHz
```

**接收端要注意的两件事：**

1. **载波恢复**：BPSK 无导频，用**平方律**
   ```
   z = x²  →  2f_c 处出现谱线（数据 ±1 被平方消掉）
   抛物线插值提精度 → f_c = 谱线频率 / 2
   ```
   **⚠️ 直接用 FFT 找最强谱线误差会到 25 kHz（符号率/4），足以让判决全错。**

2. **极性模糊**：空口可能有 180° 相位翻转，两种极性都要试，以 CRC 通过为准。

---

## 四、编码层（CCSDS 131.0-B 的编码做法）

**处理顺序：**

```
body(8B)
  → 随机化（LFSR x^8+x^7+x^5+x^3+1，种子 0xFF，多项式掩码 0x95，抽头 bit7）
  → 卷积编码 1/2（K=7，G1=1111001=0x79，G2=1011011=0x5B，第二路取反，寄存器初值 0）
  → 前置 ASM（32 bit，不随机化、不编码）
  → CADU（160 bit）
```

| 项 | 值 |
|---|---|
| 随机化多项式 | `x^8 + x^7 + x^5 + x^3 + 1` |
| 随机化种子 | `0xFF` |
| 卷积码 | rate 1/2，K=7 |
| G1 | `1111001` (0x79) |
| G2 | `1011011` (0x5B)，**输出取反** |
| 尾比特 | **不加**（编码器末尾不补零） |
| ASM | `1A CF FC 1D` |
| CADU 长度 | 32 + 2×64 = **160 bit = 20 B** |
| 单帧时长 | **1.6 ms** @100 kSPS |

## 五、帧层（8 字节 body）

```
偏移  长度  字段        说明
----  ----  ----------  ----------------------------------------
 0     1    ver         版本，固定 0x01
 1     2    rx_lo_mhz   uint16 小端，接收频段（MHz），范围 70..6000
 3     2    tx_lo_mhz   uint16 小端，转发频段（MHz），范围 70..6000
 5     1    seq         序号 0..255 递增，用于去重
 6     2    crc16       CCITT-FALSE，覆盖前 6 字节，大端
----  ----  ----------  ----------------------------------------
合计   8
```

**CRC-16/CCITT-FALSE：** poly `0x1021`，init `0xFFFF`，不反射，不异或输出，按字节 MSB first。

## 六、时序层

| 项 | 值 |
|---|---|
| 符号率 | 100 kSPS |
| 单帧 | 1.6 ms |
| 发送策略 | **连续重复**（帧间无间隔），便于接收端随时捕获 |
| 接收捕获窗口 | 65536 点 @31.25 MSPS = **2.1 ms**（≥ 1 帧） |
| 建议 | 发端至少持续 2 秒，确保接收端能抓到完整帧 |

## 七、接收处理流程（ADDA 板 PS 侧要实现的）

```
① ADC 250 MSPS 采样
② ÷8 boxcar 抽取 → 31.25 MSPS
      100.5 MHz 混叠到 100.5 − 3×31.25 = 6.75 MHz
③ 平方律载波恢复（z=x²，找 13.5 MHz 线，除 2）→ f_c
④ 下变频到 0 Hz
⑤ SRRC 匹配滤波
⑥ 抽取到符号：sps = 31.25M / 100k = 312.5
      → 用 312 / 313 + 1/8 符号相位搜索
⑦ ASM 滑动相关（容错 ≤ 2 bit）
⑧ Viterbi 译码（K=7，128 状态）
⑨ 解随机化（同一个 LFSR）
⑩ CRC16 校验
⑪ 取 rx_lo / tx_lo → 控制转发板
```

**⚠️ 第 ③ 步是关键**：不用平方律、直接用 FFT 找最强谱线，误差会到符号率的 1/4，判决必然失败。

## 九、错误处理约定

| 情况 | 处理 |
|---|---|
| ASM 未命中 | 丢弃本次捕获，重新抓 |
| CRC 失败 | 丢弃该帧，等下一帧 |
| seq 与上次相同 | 忽略（幂等，避免重复设定） |
| 连续 N 秒收不到有效帧 | **保持上次设置**（不主动 mute，避免演示中断） |
| rx/tx 超范围（<70 或 >6000） | 丢弃该帧 |

## 十、与 CCSDS 标准的关系（答辩时怎么讲）

```
✅ 完整采用 CCSDS 131.0-B 的：
   · ASM 同步字 1ACFFC1D
   · 随机化（x^8+x^7+x^5+x^3+1）
   · 卷积编码 1/2，K=7，G1/G2 多项式
   · BPSK + SRRC 成形

⚠️ 没有采用标准 TM 传输帧的 6 字节主头：
   · 因为控制量只有两个频率，不需要 SCID/VCID/帧计数那一套
   · 主头会增加 6 字节 → 帧变长 2 倍（160 → 288 bit）

⇒ 定位：CCSDS 的物理层 + 编码层 + 同步字，应用层自定义短帧
⇒ 如果评委要求完全合规，可以加主头，代价是帧时长从 1.6 ms 变 2.88 ms
```
