# ADDA ↔ 接收端 对接协议

> 目的：把两个人的口头约定变成**文件约定**，避免频率/衰减/波形格式漂移。
> 每轮只做一件事，每轮都有明确验收，卡住超过 30 分钟就升级。

---

## 一、角色与分工

| 角色 | 负责 | 不负责 |
|---|---|---|
| **A（ADDA 组员）** | ADDA 板位流时序收敛、`.coe` 烧写、DAC 输出电平与频率实测、接线 | 接收解调、转发板、CCSDS |
| **B（你）** | 接收板 IIO、频谱/解调、频率标定、衰减判定、转发板中继 | ADDA 位流、Vivado |

**共同约定**：频率、衰减、波形格式一律以 `link_spec.json` 为准，改动必须双方确认。

---

## 二、接口契约（唯一真源）

共享目录里放 `link_spec.json`，**双方动手前先读它**。

```json
{
  "version": 1,
  "updated": "2026-10-26",
  "if_hz": 100000000,
  "fs_dac_hz": 250000000,
  "fs_dac_calibrated": false,
  "sps": 200,
  "sym_rate_hz": 1250000,
  "beta": 0.35,
  "frame_format": "AA AA | len(1B) | text | CRC16-CCITT(2B, big-endian)",
  "atten_db": 40,
  "cable": "SMA J6 -> 衰减器 -> 接收板 RX1",
  "relay": { "rx_lo_mhz": 100, "tx_lo_mhz": 2450 },
  "rx_board": { "ip": "192.168.2.1", "lo_mhz": 100, "fs_hz": 30720000, "gain_db": 30 }
}
```

**当前关键值：**

| 项 | 值 | 状态 |
|---|---|---|
| 中频 | **100 MHz** | 已定（≥70 MHz 是 AD9361 下限） |
| DAC 采样率 | 250 MSPS | **未标定**（R1 之后确定） |
| 符号率 | 1.25 MSPS | 已定（`--sps 200`） |
| 占用带宽 | ~1.7 MHz | 已定 |
| 起始衰减 | **40 dB** | 必须，防烧接收端 |
| 转发板 | `lo 100 2450` | 待转发板就绪 |
| 接收板 | LO=100MHz, 30dB 增益 | 已验证可用 |

## 三、轮次计划（每轮 10~30 分钟，只做一件事）

### R0：ADDA 位流时序必须先收敛（组员单独做）

**这是当前唯一的阻塞项。**

```
P0（10 分钟）：器件改成 xc7z010clg400-1
     → 原例程是 7z020-clg484-2，速度等级和封装都不对

P1（半天）：删掉 ADC + ILA，只留 DAC 通路
     → 违例全部在 adc_dco_p (250 MHz) 域，删掉就消失
     → 你们的演示只需要发射，ADC 用不上
     → 同时删掉 XDC 里 adc_dco_p / adc_data_p 的约束

P3（30 分钟）：修 DAC 时钟约束
     → report_clocks 里现在没有 dac_dci_p，说明生成时钟没建起来
     → 补上后 DAC 输出路径才会被真正分析

验收：report_timing_summary 里 WNS ≥ 0、WHS ≥ 0、TNS = 0
```

**R0 回报（组员发你）：**

```
【R0】位流时序
器件：xc7z010clg400-1
改动：删了 ADC/ILA / 只改器件 / 其他
WNS = ____ ns    WHS = ____ ns    TNS = ____
report_clocks 里有 dac_dci_p 吗：有/没有
位流下载：成功/失败
J6 有没有波形（示波器或接收板）：有/没有
```

### R1：标定 DAC 采样率

```
组员：烧 tone_100m.coe（假设 Fs=250MSPS，中频 100MHz）
      J6 ──[40 dB 衰减]──► 接收板 RX1
你  ：扫 LO 找峰
      python rx_board.py --lo 100 --bw 3000000 --gain 40 --fft
      （找不到就依次试 --lo 200 / 400 / 80）

标定公式：
      真实 Fs = 250 MSPS × (实测频率 / 100 MHz)

你回传：一个修正版 tone_fixed.coe（用真实 Fs 生成）
组员：重新烧写，再测一次
验收：峰落在 100 MHz ± 100 kHz 内
```

**R1 回报（你发组员）：**

```
【R1】标定结果
接收 LO：____ MHz
实测峰频：____ MHz
峰值高出噪声底：____ dB
RMS：____（满量程 32767，目标 1000~5000）
推算真实 Fs：____ MSPS
下一个 .coe 文件名：tone_fixed_<Fs>.coe
```

### R2：传内容（不发单音）

```
组员：烧 text_hello.coe（BPSK "hello world"，1.25 MSPS，中频 100 MHz）
你  ：python rx_board.py --lo 100 --demod --sym-rate 1.25e6
验收：打印出 'hello world'，CRC 通过
```

**失败时的排查顺序：**
```
RMS 太小      → 衰减减小 10 dB（组员侧换衰减器）
RMS 太大      → 衰减增加 10 dB
有峰但解不出  → 检查符号率是否 1.25 MSPS、频偏是否过大
完全没峰      → 回到 R1，确认频率
```

### R3：接入转发板（你主导，组员配合调衰减）

```
你：转发板 mode relay / lo 100 2450 / txatt 25
    ADDA J6 ──[40dB]──► 转发板 RX
    转发板 TX ──[20dB]──► 接收板 RX1（先电缆，稳定后再换天线）
    python rx_board.py --lo 2450 --demod --sym-rate 1.25e6
验收：在 2450 上解出 'hello world'
```

### R4：全链路 + 遥控（最终演示）

```
遥控板解析 CCSDS → 下发 lo 100 2450 → ADDA 出内容 → 转发板变频 → 接收板解出
```

## 五、各自能独立做的自测（减少来回）

### 组员自测（不需要你）

```
① 位流能否下载、LED 是否正常
② 示波器看 J6：有没有波形、频率、峰峰值
③ 串口有没有 SPI 配置完成打印
④ 重新烧 .coe 后输出频率是否变化（验证 IP 真的重新生成了）
```

### 你自测（不需要组员）

```
① 接收板噪声底
   python rx_board.py --lo 100 --fft
② 接收板 IIO 配置是否生效
   python rx_board.py --check
③ 转发板 CLI
   （串口发 status，看 rxlo/txlo）
④ 解调算法的离线验证
   （用本地生成的波形喂给 demod_text，确认算法本身没问题）
```

**④ 很重要：先把"解调算法"单独验证过，别到现场才发现是算法问题。**

## 六、阻塞升级规则

```
卡住 < 30 分钟  → 自己查（自测清单）
卡住 30~60 分钟 → 发消息给对方，附【回报模板】
卡住 > 60 分钟  → 拉一起屏幕共享，30 分钟内决定：
                    A. 换方案（比如先跳过 ADC，只做发射）
                    B. 降指标（降低采样率/符号率）
                    C. 记录为已知问题，继续推进别的环节
```

**原则：不让一个环节堵住整条链路。** 任何一侧卡住，另一侧继续推进能独立验证的部分。

## 七、风险预案（提前说好，别临场争）

| 风险 | 预案 |
|---|---|
| 时序收敛不了 | 走 P1：删 ADC + ILA，只保留发射 |
| DAC 输出频率找不到 | 用接收板扫 50~500 MHz；必要时把 `--if` 改成 50 MHz 以下（但 AD9361 收不到 70 MHz 以下，需换接法） |
| 输出电平过高 | 衰减从 40 dB 加到 50/60 dB |
| 输出电平过低 | 减到 30/20 dB，或调 `--amp` |
| 转发板 TX 口不确定 | TX1/TX2 都试一遍 |
| 转发板网口不通 | 退回串口控制，先跑通射频链路 |
| 现场有 2.4G 干扰 | 换 5.8 GHz（`lo 100 5800`） |

## 十、一句话总结

```
R0 他把时序搞收敛（删 ADC+ILA）
R1 我标定他的采样率（扫频反推）
R2 他发文本，我解出来
R3 加转发板，变成变频
R4 加遥控指令，全链路

每轮 10~30 分钟，一次只改一个变量，
所有约定写在 link_spec.json 里，所有结论按模板回报。
```
