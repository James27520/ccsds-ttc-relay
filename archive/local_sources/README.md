本目录保存主仓库以外尚未覆盖的开发源码、构建输入及项目资料，供溯源与迁移使用，**不参与当前桌面演示，不是新的发布版本**。

## 查找与对应关系

完整盘点见 [`docs/validation/20261103_local_sources.json`](../../docs/validation/20261103_local_sources.json)。每个候选文件记录原目录、SHA-256 和仓库位置：

- `archived_unique`：独有内容保存在本归档，文件字节不修改。
- `already_covered_exact`：仓库已覆盖完全相同的内容，引用已有文件，不重复存储。
- `already_covered_line_endings`：文本仅有 CRLF/LF 差异，引用已有文本并保留原文件哈希。
- 其他分类：厂商安装包、提取的厂商示例、生成的 IP/BSP、编译产物、原始视频或下载的第三方论文；记录位置及排除原因，不作为本项目独有源码上传。

历史README中的相对链接保持原样；例如`relay_udp_work/README.md`链接的`firmware/relay_udp.elf`属于未上传的编译产物，不能从归档链接直接取得。请按清单定位源码，并按现行板级说明准备外部构建依赖。

完全相同的文件即使原目录不同，也只保存一份。因此本目录是去重后的源码档案，不能把其中任意历史子目录直接认作完整独立工程。按清单可以定位其重复文件的实际仓库位置。

## 使用限制

上传验证覆盖当前新增的多普勒代码及原默认路径回归；**没有重新验收本目录内全部历史脚本，也没有新增硬件射频验证**。
