# ADDA 的 95/100 MHz 直连候选与最小验证审查

日期：2026-10-26。范围：Z7ADDALite 原厂 ADC/DAC 例程、AD9122/AD9643 手册、已有实现产物及本机 Vivado 安装文件。本轮没有连接硬件、启动 Vivado、综合、下载位流、修改 RF 输出或修改供应商文件。本文只能确定资料和数字设计上的可行性条件，不能宣称 ADDA 与 LDSDR 已经在 100 MHz 互通。

结论：**ADDA 生成并采样 95/100 MHz 单音有明确设计依据；现有厂家位流只输出固定 1 MHz，生成 95/100 MHz 必须派生重建。100 MHz 位于当前 HB1 高抑制指标的通带边缘，但不是硬截止，极窄带 BPSK 不应直接判为不可用。首测更适合约 95 MHz 的低幅度单音，并用接收 LO 的小偏移排除直流伪峰。** LDSDR 在约 100 MHz 的调谐、模拟前端以及真实 ADC 样点仍需单独实测，软件可写 LO 不等于 RF 已通过。

## 1. 当前插值模式与 100 MHz 边界

主要来源：`D:\Z7ADDALite资料\04例程\ADDA_loop\Z7ADDA_loop.zip`，包内 `Z7ADDA_loop.srcs/sources_1/new/ad9122_config.v`：

| 配置 | 源码值 | 含义 |
| --- | --- | --- |
| DAC 数据格式 | `0x03=0x00` | 16 位二进制补码，字接口 |
| DAC 自身 PLL | `0x0A=0x00` | 关闭，使用板上 AD9516 时钟 |
| 数字通路 | `0x1B=0xA4` | PREMOD/NCO 旁路；反 sinc 没有旁路；不能认为当前存在可调数字上变频 |
| HB1 | `0x1C=0x00` | ×2 插值、Mode 0，中心 DC |
| HB2 | `0x1D=0x00` | ×2 插值、Mode 0，中心 DC |
| HB3 | `0x1E=0x01` | 旁路 |

沿用前一轮时钟配置推导：输入 `fDATA=250 MSPS`，HB1 后 500 MSPS，HB2 后 DAC 转换 1 GSPS；ADC 每通道 250 MSPS。这是静态配置推导，本轮未测有效时钟。

本地 `AD9122.pdf` 第 37 页给出的 HB1 可用**总带宽**为 `0.8×fIN1`，以 DC 为中心时对应 ±100 MHz；HB2 总带宽为 `0.5×500 MHz=250 MHz`，对应 ±125 MHz。因此当前配置的较窄数字边界来自 HB1。第 38 页表 17同时明确较宽频带的性能：

| HB1 总带宽 / 输入采样率 | 250 MSPS 对应单边范围 | 表列通带平坦度 | 表列阻带抑制 |
| --- | --- | --- | --- |
| 80% | ±100.0 MHz | 0.001 dB | 85 dB |
| 80.4% | ±100.5 MHz | 0.0012 dB | 80 dB |
| 81.2% | ±101.5 MHz | 0.0033 dB | 70 dB |

所以不能把 100 MHz 描述为“过了就没有输出”。严格保持第一行指标时，任何以 100 MHz 为中心且具有正带宽的信号都越过该指标边界；但放宽到第二行，100 MHz 周围很窄的信号仍有数字滤波依据。例如候选 BPSK 为 10 ksym/s、RRC 滚降 0.35，理想占用总带宽约 13.5 kHz，频带边缘约 100±0.00675 MHz，落在第二行内。矩形脉冲 BPSK 的无限旁瓣不能用这个有限带宽结论替代。上述指标仅针对芯片数字滤波，不代表整板模拟幅频和误码率已验证。

首测建议保持原有采样时钟，单音取 `95.125 MHz`、LDSDR LO 候选取 `95.000 MHz`，让接收复样点出现约 +125 kHz 峰；另一组用 `94.875 MHz`，峰应移到约 -125 kHz。负号受接收 I/Q 约定影响，关键是随真实发射频率可预测地移动。接收带宽/采样率必须覆盖偏移。不要把 95 MHz 信号与 100 MHz LO 配在几百 kHz 的窄接收带宽中。

若团队必须坚持 100 MHz 中心，可先用 100 MHz 单音验证，再决定是否利用上述 80 dB 范围开展窄带测试。当前不推荐为此提高 ADC 时钟：本板 ADC 型号额定最高 250 MSPS，降低采样率反而缩小 Mode 0 通带；将 DAC 输入独立升速需要改变共享时钟关系、LVDS 时序和约束，不属于最小验证。另一种后续方案是 AD9122 的复数插值/数字移频，把目标放在移位通带内部，但会占用联合 I/Q 通路，首测无需引入这一复杂度。

## 2. 固定 DDS、低幅度与最小派生改动

包内 `sources_1/ip/dds_wavegen/dds_wavegen.xci`：`DDS_Clock_Rate=250`、`Output_Frequency1=1`、`Output_Selection=Cosine`、`Amplitude_Mode=Full_Range`、`Phase_Increment=Fixed`、35 位相位累加器、16 位输出；`C_HAS_S_CONFIG=0`、`C_HAS_S_PHASE=0`。`adda_top.v` 把同一个 `dds_data` 同时送两个 DAC。没有 VIO、AXI 寄存器或串口命令可在现有位流运行时改 DDS 频率/幅度。

**改频配置主要落在 DDS IP，但不等于只改 XCI 文本即可测试。** XCI 中同时保存用户参数和派生参数（PINC、模型参数），必须通过所选 Vivado 版本重新配置/生成输出产物，重新综合、实现并生成位流；现有 `.bit` 不会随 XCI 改变。不要手改一个 XML 数值后继续下载旧位流。这里频率参数单位是 MHz。

低幅度单音可在 `dds_data` 与 `selectio_tx` 之间增加同步的有符号缩放：对补码数据做算术右移，右移 1/2/4 位分别约降低 6.02/12.04/24.08 dB；必须明确 signed 运算，不能对无符号线网用逻辑右移形成直流偏置。控制两路静音/输出时使用补码零点，保留一个有效端口即可。初始数据和复位释放也应处理。幅度缩放寄存器放在 ADC/DAC 数据时钟域并留一拍流水，避免新增长组合路径。细粒度幅度可后续乘法缩放，首测没有必要加入整套 GUI 控制。

AD9122 的满量程电流寄存器可控制模拟幅度，但不是任意大范围衰减器；原例程没有 PC 端运行时写寄存器接口，因此它不能解决“不重建直接调低”的问题。现有 `Full_Range` DDS 不应在未知连线和未知衰减器条件下直接用于 RF 接收口。

最小重建源集（均在原工程基础上派生）：

| 类别 | 保留/处理内容 |
| --- | --- |
| 自有 RTL | `adda_top.v`、`ad9516_config.v`、`ad9643_config.v`、`ad9122_config.v`、`spi_rw.v`、`rstn_module.v` |
| IP | `dds_wavegen`（DDS Compiler 6.0）、`clk_wiz_0`（Clocking Wizard 6.0）、`selectio_rx/tx`（SelectIO Wizard 5.1） |
| 约束 | `top_pro.xdc` 的引脚、电气标准、ADC/DAC 时钟和接口时序；需修正已证实的错误，见下一节 |
| 调试 | 保留 ADC1、ADC2、实际送 DAC 数据、初始化状态四个探针即可；移除把采集时钟本身作为数据观察的冗余探针 |
| 不需要 | ARM 应用、SDK 2018.3、BSP、Linux、网络或 DDR 数据搬运均不是首个固定单音的必需项 |

尚未创建或修改这个派生工程，是否重建由主任务按接线、仪器、工具和板卡状态决定。

## 3. 厂家位流、ILA 与已有时序问题

`Z7ADDA_loop.zip` 确实包含 `Z7ADDA_loop.runs/impl_1/adda_top.bit`（4,045,668 字节）、`adda_top.ltx`（15,198 字节）、同名 `.bin` 和实现报告。位流头记录器件 `7z020clg484`、Vivado 2018.3、生成日期 2025/12/08。仅凭存在这些文件不能认定其已经在用户板上通过。

原 XDC 中 ILA 深度为 4096，采集时钟 `adc_data_clk`；LTX 与 XDC 均列出 `dds_data[15:0]`、`data_adc1[13:0]`、`state[3:0]`、`data_adc2[13:0]`、`ad_dco`、`adc_data_clk` 六个探针。接收 100 MHz 时 250 MSPS 处于第一奈奎斯特区内，可以原始采样，无需高频带通折叠。AD9643 配置 `0x14=0x05` 依据该芯片手册第 31、33 页确为二进制补码、正常输出，源码“offset binary”注释不能作为解码依据。板级 ADC1 差分极性反接说明仍需在已知输入下确认。

4096 点 / 250 MSPS = 16.384 µs，FFT 栅格约 61.035 kHz。它足够初步判断 95/100 MHz 单音、幅度、削顶和噪声，FFT 宜使用合适窗口，不能因非整周期截取的泄漏误判杂散。它连 10 ksym/s 的一个完整符号时长都不到，不足以捕获 `helloworld` 短帧；文本测试后续需抽取/缓存。采集可由 Hardware Manager 导出 CSV，用现有 Python 分析，不必先做网络 GUI。

**本轮新发现并直接读取的历史实现证据：**

- `adda_top_timing_summary_routed.rpt` 写明 `Timing constraints are not met`：WNS=-4.174 ns，TNS=-281.868 ns，186 个违例端点。
- 同一 ADC 时钟域内 WNS=-0.848 ns，不能把所有违例简单归为异步跨时钟假路径；25 MHz 初始化/复位到 ADC 域另有违例，应检查复位同步与 CDC。
- `runme.log` 明确报告 `top_pro.xdc:68` 的 `selectio_tx_for_dac/inst/oddr_inst/C` 未找到；实际实例为 U10，导致生成时钟与第 76–78 行基于 `dac_dci_p` 的输出时序约束无效。

因此原位流最多作为受控的探索性起点，不可称可靠采样或量产时序基线。最小派生工程应修正正确层次及 DDR 源同步约束、处理复位 CDC，并取得完整有效约束下的通过报告；不能靠全局 false path 隐藏问题。

已有其他锯齿/方波/三角波/ROM 正弦 zip 也带 `.bit/.ltx`，但没有发现用户可选 95/100 MHz、可调低幅度的已编译单音程序。它们的非正弦波谐波不能充当本次受控 RF 单音测试源。**LDSDR→ADDA 的 100 MHz 接收成功只证明这个方向；不能拿来证明 ADDA 已经发出 100 MHz。**

## 5. 40 dB 衰减的数值意义

40 dB 对匹配负载意味着电压约除以 100、功率除以 10,000。以下只是以厂家低频例程 1.2 Vpp 描述建立的预算，忽略线损、衰减器误差与板级 100 MHz 幅频变化；不是实测上下界。

| 假设 | 衰减器前 50 Ω 端正弦电压 | 前端平均功率 | 40 dB 后电压/平均功率 |
| --- | --- | --- | --- |
| 1.2 Vpp 已是 50 Ω 负载测量值 | 1.2 Vpp | +5.56 dBm | 12 mVpp / -34.44 dBm |
| 1.2 Vpp 是高阻/开路测量，49.9 Ω 源串阻接匹配 50 Ω 后减半 | 约 0.6 Vpp | -0.46 dBm | 约 6 mVpp / -40.46 dBm |
| 上述两种情形再做数字幅度 1/4 | 约 0.15–0.30 Vpp | 约 -12.50 至 -6.48 dBm | 约 1.5–3 mVpp / -52.50 至 -46.48 dBm |

公式是 `Pavg=Vpp²/(8×50Ω)`，用于正弦平均功率。调制信号须另算峰均比，ADC/DAC 直流偏置亦不能通过 RF 平均功率概念忽略。资料没有证明衰减器型号、实际 100 MHz 插损、50 Ω 匹配、额定功率或是否隔直；固定衰减器通常不能仅凭“40 dB”标签当作隔直器。

对于 ADDA→LDSDR，40 dB 作为初始有线隔离有数值依据，但要先确认衰减器确在目标路径，并检查接收增益与样点削顶。对于 LDSDR→ADDA，不能一律照搬同样衰减：以输入衰减器的 RF 单音 0 dBm 为示例，40 dB 后约 6.32 mVpp；若按 ADDA 教程约 4.3 Vpp 满量程换算，仅约 24 个 ADC 码峰峰值，噪声/失真会影响观察。该方向需根据实际 TX 功率、幅度和 ADC 采样结果设预算，不能把“接收不到”直接归咎于不支持 100 MHz。

本轮不建议立即购置额外 RF 模块；先确认现有衰减器和测量条件，再决定如何验证。U28 供电资料矛盾沿用 `adda_research.md` 的记录，尚未核实实物，本报告不扩展推断。

## 6. 可验收的首测记录

1. 记录两板身份、实际端口、SMA/衰减器路径、位流哈希、采样率、发射幅度和接收增益；输出保持受控，未确认连线前不改 RF。
2. 将 ADDA 单音依次设在 95 MHz 附近两侧，让 LDSDR 的实际原始 I/Q 频谱峰随之移动；加入发射静音/开启对照，证明峰来自同轴路径而非接收直流/串扰。单独报告 LO 调谐状态与样点结果。
3. 反方向用 LDSDR 单音到 ADDA，在 ILA 原始样点中验证频率、幅度与静音对照；记录 14 位补码解码及通道极性。
4. 两个方向分别通过后，才能写“该频点单音有线通路可用”。仍不等于 `helloworld`、全带宽、双业务通道或长时间稳定性已经通过。

证据文件：原厂 zip 内源文件、XCI、XDC、`.bit/.ltx`、`impl_1/runme.log` 与 `adda_top_timing_summary_routed.rpt`；本地 AD9122 第 22、24、37–38 页，AD9643 第 27、31、33 页；实际工具安装目录及所链接 AMD 官方文档。无实板测量数据。
