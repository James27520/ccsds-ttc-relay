## 试验方法

先在独立工作目录准备两个诊断产物，不改供应商原始资料、共享仓库或启动介质：

1. ADDA测试位流：复用原SPI、时钟、LVDS；默认两DAC为零；DAC1受使能控制，输出硬限制为16位满幅的约1/128；频点可在低频及95/100 MHz附近切换；ILA抓取真实输出码和两路ADC数据。先检查数据格式、复位、幅度边界与时序，再下载。
2. LDSDR串口诊断ELF：复用已有改频与读回代码，保留当前PL；启动保持MUTE及两路最大TX衰减，增加真实SPI本振/锁定/增益衰减/BIST读回，不依赖网口。加载仅作用于DDR。
3. 数据分析：明确ADC位宽、二补码、样率与valid语义。若ILA时钟与被测数据异步，只报告统计，不能把筛选后的数据冒充均匀采样做可信频率测量。

诊断位流通过检查、并确认输出禁用后，再通知用户接线。拟定环路为 ADDA `DACH1/DAC1（J6）`→LDSDR `RX1`；LDSDR `TX1`→ADDA `ADCH1/ADC1（J5）`。ADDA编号有手册和原理图支持；LDSDR必须按实物RX1/TX1丝印辨认，现有资料不足以可靠描述其上下左右位置，不能拿其他板照片替代。

先取得关闭发射的ADC基线，再开启小信号；依次验证信号开/关、频点改变、转发静音/恢复与采集谱峰的对应关系。使用偏离接收LO的单音，避免把零中频直流尖峰或LO泄漏误认成业务信号。再用短文本和CRC验证内容。

本地环回需要LDSDR发回ADDA能接收的频段，不能把2450 MHz直接作为ADDA接收端测试频点。低频环回成功只证明这一频段的模拟互通，不等于2450 MHz空口已经通过。

由于缺少校准仪器，数字限幅、芯片衰减读回与ADC观测属于相对验证。估算的dBm不能写成实测输出功率；不能据此声明射频指标或法规符合性。

## 对队友方案的核对

| 建议 | 本项目处理 |
| --- | --- |
| ADDA 100 MHz有线输入，LDSDR 2450 MHz输出 | 作为单向候选；先证明100 MHz附近模拟接收能力，不以CLI接受值替代RF测量 |
| AD9361均可到6 GHz | 不能由通用驱动`ID_AD9361`判断实物芯片型号。AD9363标称325–3800 MHz；ADI说明其扩展频段通常可用但不保证性能，100 MHz可以受控测试，不能事先保证 |
| 两路双向同时做100↔2450 MHz | 两个RX共接收LO、两个TX共发射LO，不能把两个方向当作四个独立宽带本振。单向验证后需单独确定双向频率规划 |
| DAC满幅＋40 dB衰减 | 用户没有确认存在衰减器；当前先准备默认静音和硬限幅诊断输出，不能按“短线=40 dB”接线 |
| 先正弦，再BPSK文本 | 采用分阶段验证思路；当前无第三板，使用自有两板环回观测 |
| 100 MHz、1.25 M符号/秒、约1.7 MHz带宽 | 单音和调制带宽分开评估。当前AD9122插值配置在100 MHz附近接近标称低纹波边界，调制信号两侧都需纳入通带检查 |
| `1.25e6`对应输出`1.250 kSPS` | 单位不一致；应区分ADC/DAC采样率、符号率和载频，不沿用该期望输出作验收 |
| 观察100/200/400 MHz峰，按比例校准Fs | 需先识别基波/镜像/混叠和插值模式；单一峰的位置不能唯一反推实际采样时钟 |
| 32768点100 MHz COE已校验 | 未收到实际文件，不能验证该声明。250 MSPS下100 MHz周期为5样点，32768不是5的整数倍；循环播放的相位接续与杂散需要检查 |
| 仅换COE并重新生成IP | 重生成IP有必要，也要匹配ROM深度、地址位宽、回绕、数据格式、波形长度、位流和上板版本；“频率没变”不能唯一归因于缓存 |
| 相隔50 MHz就不会互扰 | 还受滤波、带外发射、耦合和接收动态范围影响；不能写成无条件结论 |
| 2.4 GHz低功率必然免许可/合规 | 频段和功率不足以单独证明合规；设备技术条件和适用规则仍需满足。当前保持有线测试，不以该段文字授权空口发射 |

## 结论更新规则

只有实际观测到受控信号经过指定外部通路，并通过开关/频移对照，才记录“模拟互通通过”；只有恢复完整内容并独立验证CRC，才记录“信息传输通过”。PLL设置/锁定、时序通过、数字自环分别记为前置结果，不提前写整体PASS。
