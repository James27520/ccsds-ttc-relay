# 早期参数演示界面

`ccsds_demo_gui.py` 属于原7010/AD936X参数表演示工具，保留原开发机 `E:\ccsds_fpga\tools` 路径。它不是当前终端1、终端2的双向通信界面，也不作为现行测控入口。

当前程序位于[sw/ground_station](../ground_station/README.md)。日常在仓库根目录运行 `start_terminal1.bat` 或 `start_terminal2.bat`，测控从终端1窗口打开，安装与连接见[双电脑说明](../../docs/two-computer-guide.md)。旧代码和历史报告保留用于追溯。
