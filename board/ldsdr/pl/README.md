# LDSDR NCO 轴线修正

这是外部 LDSDR RTL 基线的候选补丁及离线回归入口，不是完整厂商工程或已验收位流。
`baseline.json`固定四个参与仿真的源文件 SHA256；原始文件不修改，补丁在新的输出目录严格匹配应用。

原四分之一正弦表采样在区间中点，因此首项是2，末项是2047。复位后频率字为0时，
NCO输出 `(cos,sin)=(2047,2)`，而不是零相位轴线的 `(2047,0)`。
DDC对合法的12位输入 `I=Q=-2048` 计算 `(I×2047+Q×2)>>>11=-2049`，会触发数字削顶。

补丁仅在量化相位落在四个象限边界时将小分量置0，边界标记与ROM地址同步延迟。
流水级数、相位累加、非零频率及禁用时保持相位的行为不变；不屏蔽或清零削顶计数。
频率字后来改成0仍保持先前相位，不代表无条件旁路任意历史相位。

```powershell
python -B board/ldsdr/pl/verify_nco.py --rtl '<匹配基线的RTL目录>' --vivado-bin '<Vivado的bin目录>' --out '<新的外部输出目录>'
```

8192组输入遍历两个分量的全部12位编码并交替搭配正负满幅，按每4周期一个有效样点送入完整单路流水线。
原版复现1024次削顶；候选版为0，并逐样点核对输出、有效信号和9级延迟。
另检验四象限轴线、正负频率、有效间隙、相位保持和NCO延迟。两版仿真及日志均保留。

这些结果证明了数字角点修正，不等于模拟前端不会过载，也不能单独证明实板切频计数问题已解决。
完整实现须另做IP/引脚/时钟/地址检查、时序收敛及实板回归；未通过前不替换运行位流。
