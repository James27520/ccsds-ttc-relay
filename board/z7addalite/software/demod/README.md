# 实采样解调

`adda_demod.c/.h` 与 `adda_receiver.c/.h` 处理单通道等间隔 `int16_t` 样点，调用相邻 `protocol/` 完成帧校验；算法源码原样归档。

输入合同为 14 位二补码符号扩展、不左移、时间递增，31.25 MSPS（125 MSPS 每 4 点抽取），预期中频 6.75 MHz，符号率 100 ksym/s。基准块长 131072 点。原始抽取没有数字抗混叠保护，真实捕获需另核对采样格式、元数据、完整性及模拟前端。

处理包括去均值、平方谱载波估计（6.75 MHz ±40 kHz）、下变频、低通与抽取、SRRC 匹配滤波、16 相位搜索和数字帧译码。返回 1 才表示有效命令；0 表示未找到，负值表示错误。该实现是短块浮点算法，需 DDR 工作内存，不能按采样 BRAM 大小配置 PS 堆栈。

`build_and_test.ps1` 使用仓库 `sw/ccsds/ccsds_tm_tx.py` 的 SRRC 参考生成合成波形，并运行 45 项主机测试：三组 CADU、极性、频偏、时钟偏差、循环边界、噪声/单音及坏 CRC。命令和参数见板级 README。结果输出 `build/waveform_test_results.json`，不代表实板采集、RF 性能或 A9 实际耗时。

最终完整r4c M2固件已在真实A9上完成131072点SYNTHETIC波形解调，耗时278 ms且未发送UDP。真实ADC内部测试快照与normal格式验证见 [验证记录](../../../../docs/validation.md)；未接外部100.5 MHz信号，278 ms不代表连续实时吞吐率。
