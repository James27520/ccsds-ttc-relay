## 硬件条件与识别

下一阶段优先用现有两根线验证独立接收端业务链：业务发送板 TX1A → LDSDR RX1，
LDSDR TX1 → 额外接收板**已核实的 RX 端口**，无需第三根线。
业务源为名义 900.5 MHz，转发输出为 1000.5 / 1001.5 MHz；测量端改为该接收板，
其采样能力、调谐范围、数据格式及文件导出方式均须先确认，不能直接套用原发送板的 IIO 路径。
遥控板仍为 **Z7ADDALite**，其 RJ45 与 LDSDR 直连。

完整同时联动还需**独立的 100.5 MHz V2 信号源**及第三根同轴，最终接入 Z7ADDALite ADC1/J5。
额外接收板不先假定具备 TX；仅当资料、回读与实测确认其可发射且支持该频点后，
才可将其列为兼任独立指令源的候选，第三根线届时再规划。现业务发送板的双 TX 不能直接当成两套独立本振源。

额外接收板DEBUG现已连接电脑，保持SMA未接，先完成只读识别：记录设备身份、系统/驱动、
通道与扫描格式、LO/采样率/衰减回读、buffer/DDS/测试源状态；核对实际型号对应资料。
不预先给出该板的 SMA 丝印。确认接收条件后，依据资料、回读及明确接线确认指导两根业务同轴连接；
如以后评估其 TX，再单独安排受控低输出与关断验证。
资料未给出的整板输入上限不能由 ADC 芯片满量程或 ESD 器件电压代替；数字幅度与衰减设置也不等于校准 RF 功率。

## 配置边界

遥控源使用既有 V2 波形：100 MHz LO 加 +500 kHz、100 ksym/s、8 字节 body、160 bit 帧，
频率及 air_seq 显式选择。新增源的实际支持范围和 I/Q 映射仍须独立确认。
业务沿用实验文本帧与序列工具，不能称为 CCSDS 遥控帧。

RX 增益 30 dB / TX 衰减 50 dB（`levels 30 50`）仅是 ADDA 本地配置的**候选工作点**，
必须经受控确认后再配置、回读；它们不是 V2 新增字段。默认 0/89 也不能静默替代业务工作点。
LDSDR 转发 mode 必须显式管理：准备、异常及收尾保持 mode=2；满足输入/电平条件后才显式启用 mode=1。
V2 改频不被解释为自动解除静音。记录接收器 LO 及预期频偏，避免把测量端调谐变化误判为转发频移。

## 顺序验收与证据

1. 分别核对业务发送板、LDSDR、Z7ADDALite 及额外接收板身份与基线；所有源关闭，ADDA auto/network/arm 关闭、pending=0，LDSDR 静音。
2. 首先用两根线完成独立接收端的业务内容验证。需要真实 ADC 遥控复核时，先静音停发再分段换线验证；该阶段只能形成分时证据。待独立遥控源及第三根线条件齐备，才保持业务源/采集路径运行并启用 ADDA 正常自动接收与网络，执行下面的同时联动验收。
3. 每个新序号必须按顺序留证：真实 **ADC_NORMAL** CRC 有效帧 → 精确字段成功 ACK → LDSDR 独立 SPI 频率读回 → 实际 RF 频移 → 新频点的完整 CRC 有效业务帧及 payload/序列比较。
4. 重复同一指令检查去重、applied 不增及无新发送；关闭遥控源检查无误触发且业务状态保持；坏 CRC / 非法指令及 network off 拒绝检查无误应用，恢复后再用新序号验证链路。分段快照不推算跨空档漏帧，不以 CRC 有效帧声称整体 BER=0。
5. 异常与结束均独立 best effort 清理并回读：两源关闭 LO/DMA、DDS 清零、可用 TX 通道高衰减；ADDA auto/arm/network off、pending=0；LDSDR mode=2、两路 TX 89 dB、RX 增益 0、DDC/DUC=0，恢复 RX900/TX1000 MHz 并核对 SPI。失败项写入报告，不能只凭离线解码宣布通过。

本阶段不自动刷写 SD/Flash 等启动介质。现有两线允许优先完成独立接收端业务链及分段板间连接验证；
额外接收板已接DEBUG进入只读识别阶段，外观/丝印相同不能代替型号及功能确认。第三根线或独立指令源条件未齐备时，真实 ADC 控制只做分时复核，
并继续源码/启动准备；分时结果不能替代真实遥控与业务同时联动验收。后续缺线可再规划采购。
