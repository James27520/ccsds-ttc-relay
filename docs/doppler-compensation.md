# 星上双向业务多普勒补偿

2026-11-01。对象为两路 `终端 → LDSDR → 另一终端` 业务，预测、频偏测量和执行都在模拟星上端 LDSDR 内完成。无需新增 RK3588，遥控板保持其指令职责。

**源码、基础功能仿真、Cortex-A9 ELF 和 FPGA 位流构建完成；未加载演示板，未完成真实射频验收。** 原 GUI、启动入口、六根 SMA、UDP 测控协议不变。独立实验镜像启动后补偿仍为 OFF，旧镜像不访问新增寄存器。

## 处理位置

```text
终端1 → RX1 → LDSDR 原 DDC/DUC/增益链 → TX1 → 终端2
终端2 → RX2 → LDSDR 原 DDC/DUC/增益链 → TX2 → 终端1
                    ↑ 两方向独立数字补偿
原始 ADC I/Q → PL短段抓取 → LDSDR A9 平方律估计、质量检查
                              ↓ 测量修正预测残差
                    本地运动模型＋单调时钟 → 更新 NCO
```

每约 100 ms 抓取两路各 4096 组 I/Q，每约 50 ms 更新两个既有 DDC。快照覆盖每路约 0.133 ms，**不是连续解调**。抓取不阻塞原转发流，PS 每次主循环最多搬运 128 个字，连续业务仍走 FPGA。新 AXI 窗口为 `0x43C10000..0x43C1FFFF`，标识 `DPQ1`、版本 1；两路采满、完成跨时钟握手后 RAM 冻结，读完才能启动下一次采样。

## 两段传播

每个方向独立输入：输入/输出 RF 载频、上行/下行径向速度与加速度、模型有效期。正径向速度代表远离：

`fD = −fc × 径向速度 / 299792458`

`变化率 = −fc × 径向加速度 / 299792458`

RF 载频用于物理预测，不能使用 500 kHz 数字中频代替。时刻取 LDSDR 接受配置时的本地单调时钟。一次配置后，板内按时间自主更新，不需要电脑逐点下发频率。目前没有真实星历、GNSS、轨道传播或跨板时钟同步。

- 上行：从原始业务 I/Q 估计 CFO，减去名义中频；预测＋测量残差融合。测量也包含晶振误差，不能全部解释为运动多普勒。
- 下行：按运动模型预测预补偿。LDSDR 无法直接测量地面接收机处的下行误差，**下行不是测量闭环**；若需闭环，需另加地面残差回传。
- 执行：原 DDC 字加上 `word(估计上行频移 + 预测下行频移)`，DUC 和 RF 本振保持原计划。DDC 混频符号为负，因此施加的是两段频移之和的相反数。
- 地面残余约为 `实际上行 −估计上行 + 实际下行 −预测下行`。

两个方向不共用观测，也不能把遥控板 100.5 MHz 测量拿来替代 GHz 业务测量。

## 测量与退出

当前业务为 BPSK，使用 `z=(I+jQ)²` 与间隔 32 样点的复相关。30.72 MSPS 下，相关模糊间隔是 480 kHz；用名义中频选择最近分支，允许 CFO ±60 kHz。这不是任意调制解调器或盲扫频。

RMS≥8 个 ADC 计数、平方相关相干度≥0.85、削顶≤0.1%，且频偏/时间/顺序/创新门限通过，才更新残差。转发器不解业务帧，**没有业务 CRC 门限**。强同频单音也可能通过相干度判断；正式抗干扰需要导频或可信信号识别，当前用于受控有线 BPSK。

- 观测来自 DDC 之前，避免追踪自身补偿。
- 请求至采集、搬运、估计完成最多允许 20 ms，超出丢弃。当前没有首样点硬件时间戳。
- 残差新鲜期 500 ms、保持最多 2000 ms，之后回到预测；噪声不刷新有效期。
- 每段限 ±60 kHz、±1000 Hz/s、最长 300 s，段末也须在界内。50 ms 阶梯更新存在动态误差，静态结果不能作为任意动态场景指标。
- `dp off`、原测控停止/改频、租期结束、模式不符会撤销补偿。模型过期恢复保存的原 DDC。再次开启转发不会恢复旧模型，也不自动续租或解除静音。
- 检测到其他写入者修改 NCO 时退出，避免覆盖新的设置。

## 基础检查结果

没有新增大批频点扫描，只有两方向功能及必要边界检查。

| 检查 | 结果 |
|---|---|
| 方向1：上行 +12300 Hz，下行 −8000 Hz | C 估计 +12300.505 Hz，计算残差 −0.504 Hz |
| 方向2：上行 −15250 Hz，下行 +6000 Hz | C 估计 −15250.109 Hz，计算残差 +0.109 Hz |

| 无信号、重复观测、模型到期、租期失效 | 拒绝无效观测或恢复原 NCO；新租期不复活旧模型 |
| 实际板端轮询代码＋MMIO/时钟替身 | 双路搬运、自动更新、停止清理、采集卡住有界退出通过 |
| AXI/CDC 抓取 RTL | AW/W 独立到达、读反压、两次双路完整快照、冻结与复位通过 |
| A9 | 实验 ELF 已链接，原网络/BSP 依赖哈希核对；不宣称与旧编译器二进制相同 |

以上频偏来自合成 BPSK 和 RTL 仿真，**不是射频仪器实测精度或误码率**。A9 实机耗时、观测通过率和动态频移下的真实文本收发仍待验收。

布局资源：LUT 1949/17600、寄存器 3677/35200、BRAM 8/60、DSP 20/80。原设计 DSP 也是 20，新抓取模块没有增加 DSP。全设计报告仍有输入/输出延时缺失和 CDC 审查项，正 WNS 不等于接口时序及全设计 CDC 签核完成。
