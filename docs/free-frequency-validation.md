# 1 kHz 自由改频验收

本轮修改将业务输入、输出从固定配对扩展为范围内独立设置。GUI、终端后台、空口编码、遥控板 C 解码、板间整数 Hz 请求和射频回报使用同一约定，见[频率计划](free-frequency-plan.md)及[协议扩展](remote-relay-control.md)。

## 使用方式

1. 保持六根 SMA 接线。在终端1、终端2通信窗口分别连接对应板卡，测控页共享终端1连接。
2. 测控选择“设置频率”。输入业务中心：输入 1980.100–2009.900 MHz，输出 2170.100–2199.900 MHz。两项可独立编辑，最多三位有效小数，最小设置步进 0.001 MHz；多余的末尾零允许，小于 1 kHz 的非零尾数拒绝。
3. 点击“生成指令”，再点击“发送指令”，等待真实射频回报确认。改频完成后转发板保持静音。
4. 在相同频率值下选择“开启转发”，再次生成并发送。成功后两终端恢复业务接收，可相互发送新文本。本机共同启动的终端2窗口跟随已确认频率计划。
5. “查询状态”和“停止转发”不需要填写频率，不受无效草稿影响。开启最多 5 分钟，查询不续期；过期后需重新开启。

输入 2000.000、输出 2190.251 MHz 是有效独立组合。2200 MHz 中心因超出预留带宽边界后的范围被拒绝，界面直接显示范围，不能将它保存成可发送的指令。界面回报与指令请求分开显示；频率回读成功不代表已开启转发，发送记录也不代表对方已收到。

## 保留的失败及边界

首次加载遥控板新应用后，其 UDP 序号重置，而未重启的 LDSDR 仍保存原序号。新“开启”命令返回 -2，已由维护工具发送只读查询恢复序号连续性，未绕过防重放，也未将失败标作成功。此过程留下的失败累计保留。单板复位后的自动会话协商和持久化序号尚未实现。

相邻频点和边界测试各发生一次终端1高速 USB 上传不完整，分别收到 29,598/29,600、29,595/29,600 字节。长度和 SHA256 校验拒绝使用，连接清理并保留待重试；两次整轮测试均保留失败标志，不覆盖原记录。已将上传改为 460800 波特率、1024 字节分块，并按每块线上传输时间增加 4 ms 间隔；下载仍为 921600。恢复握手、长度和 SHA256 校验、取消及超时边界保留，无自动射频重发。上传及终端相关 74 项检查通过；连续实测结果另列，不能据此宣称 USB 长期稳定。

首次新查询事务中，PHY 检出一个长度 170 字节、碰巧通过 CRC 的非遥测候选，同时收到 7 个正确 ATM2 帧。原主机将通用 PHY 帧全部交给事务校验，导致合法回报也被拒绝。已在遥测解码层按 ATM 结构分类，未知或无效结构单列 `rejected_frames`，不计有效回报；合法 ATM 的 CRC、操作、序号、频率及跨事务一致性校验保持严格。原始 IQ 重解恢复这 7 帧，仍将原在线事务记失败，不追改历史成功标志。

六线接法不变，测控与终端1业务仍因共用本振分时运行；两方向业务可并行。两方向共用转发板 RX/TX 本振，不支持四个完全独立的本振设置。双电脑之间自动同步计划、上电持久运行、全频段频谱质量及长期误码率不在本次验收范围。

本轮10月31日验收使用台架有限服务：每次启动最多 600 秒或 16 条指令，结束后需由维护工具重新启动服务。它与“开启转发”的 5 分钟期限是两个独立计时器。11月1日另增常驻监听与本地接收恢复，见[后续验证](standby-recovery-validation.md)。应用仍仅驻留 RAM，断电后需重新加载；不能将通路验证写成已完成无人值守上电运行。
