# 真实ADC遥控与业务转发分时验证

2026-10-28，真实100.5 MHz指令经Z7ADDALite的ADC_NORMAL、PS解调和UDP/ACK，完成修正版LDSDR的四组频率设置。保留最后的RX900/TX1001 MHz设置，停发换线后，独立接收板恢复了正确业务序列。业务采样期间没有再次通过本地命令或UDP设置转发频率。本轮是两根SMA的分时验证，尚未验证指令与业务同时运行。详细数值和证据索引见[验证摘要](validation/2026-10-28-adc-business-staged.json)。

## 接线与工作点

| 阶段 | 第一根SMA | 第二根SMA |
|---|---|---|
| 真实遥控 | 发送板TX1A → Z7ADDALite ADC1/J5 | LDSDR TX1 → 独立接收板RX1A |
| 业务验证 | 发送板TX1A → LDSDR RX1 | LDSDR TX1 → 独立接收板RX1A |

换线前均确认停发/静音，只移动第一根线的接收端。Z7ADDALite与LDSDR的网线、全部DEBUG USB保持连接，无天线、无重启。独立接收端仍按Windows完整USB实例和IIO hw_serial双重绑定，全部业务采样来自COM18；板卡身份边界见[独立接收板验证](independent-receiver-validation.md)。

指令源使用100 MHz LO加500 kHz基带、100 ksym/s V2波形，数字峰值0.1、TX衰减30 dB。控制阶段LDSDR保持mode=2、RX增益0、两路TX衰减89 dB。业务阶段源改为900 MHz LO加500 kHz，源与转发TX衰减50 dB、转发RX增益30 dB；这些增益、衰减及转发模式由本地配置，不是V2空口字段。接收端固定RX LO读回1000749998 Hz、2.5 MSPS、3 MHz带宽、增益30 dB。数字幅度和衰减值不代表已校准的绝对RF功率。

## 真实指令与设置保持

复用现有V2波形生成器和C接收器，先完成四组命令、两种时序/极性条件的8个离线检查，再执行实板接收。离线检查不计入RF验收。

| 序号 | 请求RX/TX（MHz） | 独立SPI读回RX/TX（Hz） | applied |
|---:|---|---|---|
| 160 | 900 / 1000 | 900000000 / 1000000000 | 30 → 31 |
| 161 | 901 / 1000 | 900999998 / 1000000000 | 31 → 32 |
| 162 | 901 / 1001 | 900999998 / 1000999998 | 32 → 33 |
| 163 | 900 / 1001 | 900000000 / 1000999998 | 33 → 34 |

四笔均有ADC_NORMAL有效解码、精确匹配ACK及独立SPI读回；没有使用UART_NETTEST或本地lo代替真实指令。每笔重复波形再观察2秒，仍可解出相同序号，但没有新UDP应用。关闭源后观察2秒，decoded=244、applied=34不变，pending=0、failures=0。LDSDR的0x010保持0x88，PLL锁定，BIST/环回测试关闭，SPI错误计数0。

随后关闭ADDA auto/network/ARM，保留seq163产生的900/1001 MHz设置再换线。业务runner绑定已通过的控制结果，开始及采样结束均核对SPI和ADDA状态；applied始终34，期间未出现新的转发频率写入。该轮保留源波形、板端采集/解码串口记录、ACK和SPI证据，未另行导出遥控板原始ADC快照。

业务使用既有实验BPSK文本序列`SEQ000:ABCD`至`SEQ007:ABCD`，不是遥控V2帧。每窗8192组I/Q、3.2768 ms，原始文件逐份校验SHA-256，并以当前序列工具重新解码，与原报告完全一致。

正例的平均载波偏移为+750088.225 Hz，结合固定接收LO推算输出约1001.500086 MHz，符合900.5 MHz输入经900/1001 MHz本振变频后的预期。频率参考为板卡LO和采样时钟，未使用校准频率仪。正例目标频带约−54.61～−54.77 dBFS，静音及关源约−74.12、−73.76 dBFS。

960个CRC选定同步与已知序列锚定后的条件比较bit无差异；全部窗口ADC削顶分量0，逐窗LDSDR削顶增量0。负例没有恢复有效帧。短快照不用于推导整体BER、帧交付率或跨窗口无漏帧，2秒观察也不代表长期误触发统计。
