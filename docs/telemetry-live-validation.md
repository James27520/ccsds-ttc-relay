# 测控下行 GUI 单次采集验证

2026-10-28，在既有三根 SMA 接线下，将“接收窗口准备 → DAC 有限发送 → IQ 回传 → 独立解码”接入浅色地面站。控制器和实际 GUI 各完成一次发送，分别收到 4 个 CRC 正确帧，合计 8 帧、2 份新快照。GUI 从请求到结果事件约 16.9 秒；这是单次分段采集，不是连续实时遥测。

## 接线与工作点

保持发送板 TX1A → LDSDR RX1、LDSDR TX1 → 独立接收板 RX1A，以及 Z7ADDALite DAC1/J6 → 原发送板 RX1A/JP2。网线和 DEBUG USB 不变，无天线；本轮没有重新下载 PL/ELF，也没有写 Flash/SD。使用前一阶段 candidate04 及匹配 PS 程序。

DAC 保持名义 90.5 MHz、100 ksym/s、数字峰值 128/32768、单次约 33.6 ms。下行接收 LO 90 MHz、采样率 2.5 MSPS、带宽 3 MHz、手动增益 20 dB。每份 IQ 为 262144 个复数样本、1048576 字节，覆盖 104.8576 ms；完整流程的大部分时间用于 DEBUG 二进制回传。

## 会话与控制边界

用户选择遥控板和下行接收 SDR 的两个端口，先只读核验，再绑定连接。绑定令牌只在当前进程使用一次，连接时重新核对 USB、接收 SDR 的 Linux boot ID、固件模型及 IIO 身份。每次采样重新核验。遥控板没有 boot nonce，使用 USB 与 uptime 连续性检查；这不能认证设备，也不能区分所有重启情况。

本次实际接收仍来自 COM19，其 USB 序号短、IIO 序号为空。因此新增的是限定用途的当前会话接收适配器，常规业务 Console 的稳定身份检查未放宽，也没有新增发射白名单或持久化身份。COM 号不能作为下次连接的固定角色。物理接线核对和本次实收证据见[前一阶段记录](telemetry-rf-validation.md)。

打开窗口只枚举端口；核验不配置硬件。连接检查板卡空闲后配置接收、保持 SDR 停发，不启动 DAC。只有点击“发送并接收一次”才请求一次有限发送；“仅采样”不会发出 tmclear/tmsend/tmstop。接收缓冲就绪后才提交发送，丢失发送回执时不自动重试。结果必须经过长度、SHA256、IQ 独立解调及 GUI 帧 CRC 复核；USB 查询只记录为参考，不输入解码器。

停止或关闭会清空未执行任务，等待高速串口恢复，清理本次拥有的采样进程并释放端口。清理按私有采样目录、PID 和启动时刻定位，不全局终止其他采集。发现其他任务已占用板卡时，拒绝开始，不擅自停止该任务。

## 实板结果

| 操作 | DAC 快照序号 | 有效帧 | 完整流程耗时 | 结果 |
| --- | --- | --- | --- | --- |
| 控制器发送前仅采样 | — | 0 | 16.44 s | 静默对照 |
| 控制器发送一次 | 16 | 4 | 16.88 s | 一份新状态快照 |
| 控制器发送后仅采样 | — | 0 | 16.43 s | 静默对照 |
| 实际 GUI 点击发送并接收 | 17 | 4 | 16.92 s | 界面显示四帧、序号与三阶段来源 |
| 实际 GUI 仅采样后关闭窗口 | 未增加 | 不发布结果 | 取消流程 | 等待传输恢复后退出，串口可重开 |

两次有效发送的快照不同，但都携带之前已存在的 UART_NETTEST 指令序号 232、RX900/TX1000 MHz 状态；本轮没有新增 ADC_NORMAL 指令或新的 UDP 改频事务。每份快照重复发送四次，不是四条独立命令。收到的 ACK 字段不是独立 SPI 证据。

两个完整静默对照均为 0 帧。取消操作留下的原始 IQ 另行复算也为 0 帧，但没有发布 capture 成功事件或解码报告，不计入完整成功采集。全部五份原始 IQ 重新计算 SHA256 并独立解码，与已有报告逐帧负载及 CRC 一致；均无削顶。有效窗口 RMS 约 19.62/19.81 码，静默约 1.68–1.73 码。

软件回归 135 项通过，包括绑定失效、串口互斥、接收未就绪、发送回执丢失、取消、第三方任务占用和窗口退出。最后调整耗时与进度提示后，RF 窗口 23 项针对性测试通过。实际 GUI 关闭发生在 IQ 回传期间；最终恢复 115200 波特、释放串口，取消操作没有额外发送。

## 收尾与复核资料

独立进程重开各串口复查：两个 Linux SDR 的 TX LO powerdown=1、RX/TX buffer=0、TX 衰减均 89 dB；遥控板发送序号 18、pending/stopping=0、状态 0x28、diag=0、DAC verified/finished=1。LDSDR RX900/TX1000 MHz、TX 衰减 89 dB，两个 PLL 锁定、SPI 错误 0。所有检查端口随后关闭；三根 SMA 保持原样。
