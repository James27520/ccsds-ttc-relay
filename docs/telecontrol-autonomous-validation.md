# 板端自主测控与第二版改频窗口验证

2026-10-29，沿用 candidate04 ADC/DAC 位流，新增 PS 自动服务并临时 JTAG 加载。两笔控制器事务和一笔第二版 GUI 实际操作通过，共恢复23个CRC正确的射频下行帧。没有写入Flash或SD卡。详细数据及文件摘要见[验证索引](validation/2026-10-29-telecontrol-autonomous.json)。

## 本轮改变

此前台架工具对每笔事务通过调试串口触发ADC采集、解调及DAC发送。本轮在一次启用服务后，这些步骤由遥控板PS执行；地面控制器和改频窗口只持有本地发送板串口。ADDA与LDSDR的调试接口仅用于事前准备、事后独立检查，没有参与每笔指令调度。

实际路径为：电脑1生成V2指令 → 发送板100.5MHz射频 → ADDA ADC1/J5 → PS C解调 → 以太网UDP → LDSDR执行与ACK → ADDA DAC1/J6的90.5MHz回报 → 发送板RX1A实际采样 → GUI解码显示。

上行和下行顺序使用同一台SDR，业务输入本轮未连接。下行仍为实验ATM1格式，CRC和事务匹配不是身份认证，不表示完整CCSDS或NTN标准符合性。

GUI一笔晚于首次序号0租约600秒到期，且启用了新一轮板端服务；不是同一服务中重复接受序号0。每笔射频返回的decoded/send/ACK均为ADC_NORMAL，频率、空口序号、UDP序号及事件顺序匹配。板端applied由0增至3、failures保持0。独立LDSDR诊断另行读回900000000 / 1000999998 Hz、900000000 / 1000000000 Hz、900000000 / 1000999998 Hz，与相应ACK一致。

GUI显示业务中心频率900.5 → 1001.5 MHz，回报本振为900.000000 / 1000.999998 MHz；两者相差固定+0.5MHz调制偏移。界面成功来自当前实际IQ，不从预期值、USB TM1或历史报告填入。独立SPI仅属于台架审计，GUI不宣称直接读取星上SPI。

每份IQ包含262144个复数样本，2.5MSPS下覆盖104.8576ms；RMS约27.67、26.75、26.71码，均未检测到削顶。原始IQ离线重新解码后，帧数、CRC及完整快照与在线结果一致。多帧是同一冻结快照的重复发送，不是多笔独立执行，也不能据此计算连续链路BER。

## 自动服务与停止边界

`service on`仅在网络就绪、采集空闲、DAC配置核验通过、转发参数为gain0/atten89且没有未完成事务时接受。启动默认为关闭，最多运行600秒或接受16笔事务。当前服务内使用256位表抑制空口序号重用，先前最后一笔已应用序号也不能再次接受。

匹配ACK后冻结一份420字节ATM1发送数据，包括快照序号、uptime与三阶段记录。延迟3秒后，每50ms尝试发送一次33.6ms波形，20秒窗口内最多400次；慢轮询跳过发送机会，不补发延长窗口。结束后恢复ADC监听。失败事务不返回成功包。

`service off`、`network off`、`auto off`、`arm off`、`capture cancel`及`tmstop`可停止服务；服务活动期间拒绝冲突的手动采集、解调、nettest或tmsend。停止取消排队回报、终止ADC/DAC并解除ARM；已由LDSDR执行的改频不会被“断开电脑”撤销。

本轮GUI测试后观察到服务自行到期：`active=0 state=0 reason=2 remaining_ms=0`，接受/完成各1笔、失败0、回报发送400次。随后网络关闭，ARM/pending为0，DAC空闲。两台Linux SDR均读回TX本振关闭、TX/RX DMA为0；LDSDR保持最后一次实际设置900/1001MHz、gain0/atten89。没有恢复业务输入接线。

## 启动与复现

1. 使用验证索引绑定的candidate04位流、ps7_init与新`adda_m2_candidate_tm.elf`；只对已核对线缆的遥控板进行临时JTAG加载。不要把此PS固件与没有DAC外设的r4c混用。
2. 保持发送板TX1A → 遥控板ADC1/J5、遥控板DAC1/J6 → 同一发送板RX1A；ADDA与LDSDR网线直连。LDSDR TX1 → 独立接收板RX1A保持不动，全部无天线。
3. 台架先确认发送板停发、LDSDR gain0/atten89。遥控板执行`tmclear`、`levels 0 89`、`network on`、`service on`，检查`service status`进入LISTEN，再释放遥控板调试串口。这是每轮服务的一次准备，不是每笔遥控指令的代替路径。
4. 启动仓库根目录`start_control.bat`，选择已确认实物对应的本地发送板，连接、输入已验证工作点、生成并发送。当前在线中心频率仅开放900.5/901.5 → 1000.5/1001.5MHz。其他自由输入保留为方案，尚未授权任意频率实际发射。
5. 等待射频回报；超时或关联不符表示结果未确认。每次发送保存实际IQ、解码JSON、请求与日志。结束时正常断开；如停止本轮台架服务，再执行`service off`与`network off`并核对DAC空闲。

首次连接确认本地TX关闭后等待至少30秒，再允许发出新指令，避免残留有限回报与新事务重叠。程序内部管理序号；跨进程600秒租约保存在用户目录，并通过文件锁和原子替换避免两个窗口同时分配同一序号。缺少唯一USB身份的板卡仅受当前USB/Linux启动会话约束，COM标签不是永久设备认证。
