# 遥控链路 V2：中频指令与转发板控制

更新：2026-10-28。适用于“发送端 → Z7ADDALite 遥控板 → LDSDR 转发板”。接收源码已归档到`board/z7addalite`，UART_NETTEST双板UDP及真实100.5 MHz有线指令驱动的ADC_NORMAL自动解调、UDP、匹配ACK和LDSDR独立SPI读回均已验证。[GUI实板验证](validation/2026-10-28-gui-loop.json)另通过启停及ADC_NORMAL自动控制，GUI nettest按钮未实测。结果限本次实物和工作点，未验收业务RF、全频段、误码率或长期连续运行，见 [真实输入闭环摘要](validation/2026-10-28-analog-loop.json)。

## 三种格式的边界

| 路径 | 格式 | 使用位置 |
|---|---|---|
| 早期遥测演示 | 40 字节帧，编码后加 ASM 共 672 bit | 现有 `sw/ccsds`、原 RTL 和 GUI |
| 当前中频遥控指令 | 8 字节 body，编码后加 ASM 共 160 bit | 发送端 → Z7ADDALite ADC |
| 转发板网络控制 | 26 字节 RF_SET，不含 ASM | Z7ADDALite → LDSDR UDP |

三者不能互换。中频指令没有携带增益、衰减、带宽或工作模式；这些参数不能从未定义字段中推导。

## 物理与采样参数

| 项目 | 当前约定 |
|---|---|
| 传输介质 | SMA同轴有线连接；本轮为发送板TX1A/JP1 → 遥控板ADC1/J5，绝对功率未校准 |
| 中频中心 | 100.5 MHz；发送参考为 100 MHz LO 加 +500 kHz 复基带偏移 |
| 调制与成形 | BPSK，0 → +1、1 → −1；SRRC，β=0.35、跨度 8 符号 |
| 符号率 | 100 ksym/s；不是 1.25 MSPS 旧文本信号方案 |
| 发端采样率 | 2.5 MSPS，25 样点/符号 |
| 理想成形带宽 | 135 kHz，来自 100 ksym/s × (1 + 0.35)，不是实测占用带宽 |
| 遥控板 ADC | 名义 125 MSPS，双通道 DDR 1:8 解串，每向量 4A + 4B |
| 算法输入 | 一路固定每 4 点取 1 点，31.25 MSPS；14 位二补码符号扩展为 int16 |
| 捕获窗口 | 131072 点，256 KiB，4.194304 ms |

100.5 MHz 经 125 MSPS 采样后折叠至 24.5 MHz，再经四倍固定抽取折叠至 6.75 MHz。当前抽取不包含数字抗混叠滤波，不能用内部 PN9 测试证明外部模拟链的性能。

65536 点只有 2.097152 ms；连续重复 1.6 ms 帧时，任意起点不一定包含完整一帧，因此使用更长的捕获窗口。发送参考持续重复相同指令；改变指令时必须更新序号。本轮四组真实指令通过控制闭环，每组重复帧观察2秒未产生新UDP；长期连续运行与误码率仍需另测。

## 指令 body

| 偏移 | 字节数 | 字段 | 编码 |
|---|---:|---|---|
| 0 | 1 | version | 固定 `01`；“V2”指系统架构版本，不是此字段值 |
| 1 | 2 | rx_lo_mhz | uint16，小端，整数 MHz |
| 3 | 2 | tx_lo_mhz | uint16，小端，整数 MHz |
| 5 | 1 | seq | uint8，0..255，发送新指令时更新 |
| 6 | 2 | crc16 | 大端，覆盖前 6 字节 |

CRC 使用 CRC-16/CCITT-FALSE：poly=0x1021、init=0xFFFF、不反射、xorout=0。协议接受的频率数值范围为 70..6000 MHz；这是字段检查范围，不能作为 LDSDR 或其他射频板的硬件频段保证。

## 编码与同步

```text
8 字节 body（含 CRC）
  → 逐字节 MSB first
  → 随机化（每帧复位为 FF）
  → K=7、rate 1/2 卷积编码（初始状态 0，不加尾比特）
  → 前置未随机化、未编码的 ASM 1A CF FC 1D
  → 20 字节 / 160 bit / 1.6 ms
```

- 随机化每次输出旧状态 bit7；反馈为旧 bit0、bit2、bit4、bit7 的异或，状态左移并将反馈写入 bit0。
- 卷积编码每次将输入比特移入 7 位寄存器低位；先输出与 `0x79` 相与后的奇偶校验，再输出与 `0x5B` 相与后的奇偶校验取反。
- K=7 对应 6 位记忆、64 个最小 trellis 状态。由于无尾比特，接收端选择最小度量末态，不能强制回到状态 0。
- 接收端尝试两种 BPSK 极性，必须通过版本、范围和 CRC 检查。当前 ASM 搜索允许最多 2 bit 错误。
- 这套项目短帧不是标准 TM/TC 传输帧或完整 CLTU 实现；使用相关同步和编码方法不等同于通过标准符合性认证。

### 金标准向量

| rx / tx / seq | body（8B） | CADU（20B） |
|---|---|---|
| 100 / 2450 / 0 | `01640092090077ab` | `1acffc1dbcd9014c82bf4b2c0b3894c10ddfdc50` |
| 120 / 1000 / 1 | `017800e8030118f9` | `1acffc1dbcd902e425bf7178a92646027b434d99` |
| 2400 / 2450 / 7 | `0160099209077d3d` | `1acffc1dbcd90178796fe89c0b3894fb8771de0a` |

发送和接收实现均应与上述字节逐一一致。当前主机 C 测试与板载 ARM 帧自测已通过三组向量；无尾比特短码的测试存在末端单比特错误由 CRC 拒绝的情况，不承诺任意单比特错误均能纠正。

## PS 接收处理

当前 C 实现：去均值 → 平方律载波估计 → NCO 下变频 → 低通并抽取至 1.25 MSPS → SRRC 匹配滤波 → 分数符号位置搜索 → ASM / 双极性 / Viterbi → 解随机化 → CRC。

平方律在预期 13.5 MHz 附近搜索并排除 DC，再将频率除以 2；不直接把原始 BPSK 信号最强谱线当作载波。当前搜索范围为输入别名 6.75 MHz ±40 kHz，后续应由实物频偏与误帧表现验证。

ADC 内部训练码和合成自测波形不允许自动触发转发板改频。正常 ADC 快照必须通过模式、训练、配置回读、样点数量和完整性检查，且网络就绪、转发已显式启用，才允许提交解出的指令。

## UDP RF_SET 与 ACK

当前地址为遥控板 `169.254.9.11:5006`、转发板 `169.254.9.10:5005`，子网掩码 `255.255.0.0`。这组地址已完成直连双板RF_SET/ACK及独立频率读回验证；换网络时仍需检查地址冲突，并确认LDSDR运行匹配的UDP固件。

| 字节偏移 | 长度 | 字段 |
|---|---:|---|
| 0 | 2 | 大端 `0101`，沿用旧 RF_SET 头 |
| 2 | 2 | 大端 `C000 OR transaction_seq14` |
| 4 | 2 | 大端 `0011`，沿用旧实现“18 字节负载减一”的长度约定 |
| 6 | 8 | 接收频率，uint64，大端，Hz |
| 14 | 8 | 转发频率，uint64，大端，Hz |
| 22 | 1 | 接收增益，0..76 dB |
| 23 | 1 | 发射衰减，0..89 dB |
| 24 | 2 | 前 24 字节 CRC-16/CCITT-FALSE，大端 |

这里保留旧服务器线格式，不借文档更新改变头字段、长度或字节序。增益和衰减来自显式配置，当前候选默认值分别为 0 dB 和 89 dB。频率指令本身不会要求解除转发板静音。

例如 rx=100 MHz、tx=2450 MHz、事务号 `0x123`、gain=0、att=89：

```text
请求：0101c12300110000000005f5e100000000009208088000590849
回执：rc=0 seq=291 rx_hz=100000000 tx_hz=2450000000\n
```

回执为 ASCII，结尾 LF 或 CRLF，不是旧串口方案的二进制 `ACK_TM`。客户端检查来源 IP/端口、字段格式、事务号、`rc=0` 以及频率读回误差不超过 10 kHz；成功后才更新本地已确认状态。

当前重试间隔为 250 ms，最多发送 3 次，同一事务重用同一报文及事务号。超时、错误或不匹配的回执都不记为成功；回执丢失时远端仍可能已经执行，不能假定远端保持旧值。

空口 seq8 与 UDP seq14 是两套序号。对最后已确认的空口指令，相同序号且内容相同则去重；相同序号、内容不同则报冲突。仓库离线生成器`sw/tools/telecontrol_waveform.py`要求显式`--seq`；改变指令时更新序号，持续重复同一指令时保持不变。旧交接脚本固定`seq=0`，不能直接用于变更指令，也不能通过关闭接收端去重来掩盖。当前约定不提供跨重启会话的鉴权或重放保护。

UDP 配置回执不代表射频输出存在，也不代表业务信息已被另一块板接收。频率寄存器、实际输出频点和内容传输分别验收。

发送波形、离线采样分析与新发送板接入前提见 [真实输入联调准备](signal-input-bringup.md)。
