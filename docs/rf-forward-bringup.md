# 业务信号转发联调

2026-10-28 已完成第一路有线单音变频转发，并修正 LDSDR 接收 I/Q 顺序。**900.5 MHz 输入 → 约 1000.5 MHz 输出，以及输出增加 1 MHz 的对照均通过。** 固定版固件另通过三组双板 UDP 改频回归。GUI 和遥控协议实现维持现有版本，交由后续审查。完整数值和产物校验和见[验证摘要](validation/2026-10-28-rf-forward.json)。

## 本轮范围

使用现有 7010_AD9363_SDR 的 TX1A 提供单音，其 RX1A 接收 LDSDR 的变频输出。先验证第一路有线转发，不依赖额外接收板或频谱仪。Z7ADDALite 保持 USB 和以太网连接，自动解调、网络控制和发送授权均关闭。

这是一项独立的业务链测试。借用同一块 SDR 同时发业务信号和收转发结果，并不意味着它能同时发送 100.5 MHz 遥控信号与 900.5 MHz 业务信号；双 TX 共用本振，完整系统的并行链路另行安排。

| SMA 线 | 起点 | 终点 |
|---|---|---|
| 第一根 | 发送板 TX1A / JP1 | LDSDR RX1 |
| 第二根 | LDSDR TX1 | 发送板 RX1A / JP2 |

上述两根线已由实物持有者确认接好。遥控板本轮不接 SMA；原双板网线和所有调试 USB 保持不动，不接天线。接口依据为对应板卡厂商手册及原理图，不能把另一块板的端口排列直接套用。

## 已完成预检

- 三组调试 USB 身份与前一阶段一致。
- 发送板 Linux 接收设备 `cf-ad9361-lpc` 可通过 DEBUG 串口控制 `iio_readdev`，完成一次有界采样和数据回传。
- RX1 I/Q 为交错小端、有符号 12 位、16 位存储，采样率 2.5 MSPS。本次回传 8192 组 I/Q，共 32768 字节，板端及主机 SHA-256 一致。
- RX1A 未接信号时，接收 LO=1000 MHz、手动增益 30 dB、带宽 3 MHz；复数 RMS=1.8613 ADC 码，范围 −4～5，没有削顶。这只是底噪基线。
- 发送板 `bist_prbs`、`bist_tone`、`loopback` 均读回 0；TX 本振关闭、DMA 缓冲关闭、八路 DDS 幅度为 0，两路 TX 衰减均为 89 dB。
- LDSDR 独立 SPI 读回 RX=900000000 Hz、TX=1000000000 Hz；第一路 mode=2、DDC/DUC=0、数字增益 0x800、DC blocker=0、接收增益设置为 0、发射衰减设置为 89 dB。采样率保持 30.72 MSPS。
- Z7ADDALite 读回 auto=0、network=0、armed=0、pending=0。

LDSDR 活动 PL 的完整位流来源尚未确定。本地旧版 RTL 两路共享控制，新版独立控制第二路；实板 `0x2C～0x3C` 全零，不能按新版第二路默认 `0x2001` 推断其行为。当前仅完成第一路实测，不把源码中的第二路控制能力写成已验证功能。

## 测试设置与判据

| 项目 | 设置 |
|---|---|
| 信号源 | TX LO=900 MHz，复数单音偏移 +500 kHz，归一化幅度 0.1 |
| LDSDR | RX LO=900 MHz，TX LO=1000 MHz，DDC/DUC=0，mode=1 |
| 预期输出 | 1000.5 MHz |
| 测量端 | RX LO=1000.75 MHz，Fs=2.5 MSPS，手动增益 30 dB |
| 预期基带峰 | −250 kHz；将 LDSDR TX LO 改为 1001 MHz 后应为 +750 kHz |
| 电平 | 源端与转发端均从 60 dB 发射衰减开始，验收使用两端各 50 dB；LDSDR 接收增益 30 dB |

两个 TX 均以高衰减状态接线；短 SMA 线不作为衰减器。若信号过弱，依据真实采样逐步调整，当前脚本限制发射衰减不得低于 30 dB。该限制是本次无外置放大器有线实验的工作边界，不是绝对输出功率测量。

依次记录关闭信号、正常转发、转发静音、源端关闭以及 TX LO 增加 1 MHz 的采样。每份数据检查长度、SHA-256、ADC 格式、削顶与状态读回。验收要求：

1. 正常输出相对转发静音、源端关闭的目标频带功率均下降至少 15 dB。
2. 正常与移频输出的目标频带功率相对频带外中位噪声估计均高至少 15 dB。
3. 两个峰值偏移距预期各不超过 10 kHz；实测频移距 1 MHz 不超过 5 kHz。
4. 不出现接收削顶或 LDSDR 削顶计数增加，且独立 SPI 读回与设置一致。

源端设置 90 秒自动停发保护；异常清理依次尝试关闭 TX 本振、恢复两路 89 dB 衰减、清零 DDS、停止本次创建的 DMA 进程。LDSDR 恢复 mode=2、89 dB 衰减和 900/1000 MHz，并再次检查独立 SPI 读回。采样完成与 RF 验收通过分别记录。

频谱分析工具为 [`sw/tools/rf_tone_check.py`](../sw/tools/rf_tone_check.py)，五项离线测试通过，覆盖两个已知频率/幅度的合成信号、静默数据、ADC削顶、格式和频率参数错误。可运行 `python -B -m unittest discover -s sw/tools -p test_rf_tone_check.py -v` 复查。它输出 ADC 参考 dBFS，**不能当作校准后的 dBm 或频谱仪测量**。

## I/Q 修正与固定版实测

原设置 `pp_rx_swap_enable=1` 时，900.5 MHz 输入出现在约 999.5 MHz，基带符号反转。旁路模式下单独将 RX LO 从 900 改为 901 MHz，输出反而上移约 1 MHz；DUC +100 kHz 的输出方向正确。重启恢复后，在诊断版上重现，再仅清除 `0x010` 的 RX swap 位，目标输出恢复到约 1000.5 MHz。

固定版默认 RX swap=0、TX swap=1，寄存器读回 `0x88`。以下为重新加载固定版后的独立验收，没有用临时 `iqswap` 命令补改：

| 状态 | 接收基带峰值（Hz） | 目标频带功率（dBFS） | 结论 |
|---|---:|---:|---|
| 两端低输出基线 | 不认定为载波 | −80.80 | 底噪参考 |
| 正常转发，TX LO=1000 MHz | −250075.56 | −50.44 | 符合 −250 kHz 目标 |
| 转发 mode=2 | 不认定为载波 | −80.87 | 目标信号下降 30.43 dB |
| 源端关闭，转发 mode=1 | 不认定为载波 | −80.55 | 目标信号下降 30.12 dB |
| TX LO=1001 MHz | +749936.67 | −50.78 | 峰值移动 1000012.23 Hz |

每份为 8192 组 I/Q，回传长度、SHA-256 和格式检查通过。接收 LO 实际读回 1000749998 Hz；对应输出估计约 1000499922 Hz 与 1001499935 Hz，频率基准仍来自板卡。活动与移频信号的频带对噪声中位数估计分别高 30.71、30.43 dB。该指标不是校准 SNR，dBFS 不是 dBm。

五份快照均无接收削顶，采集前后 LDSDR 削顶计数增量均为 0；累计计数原本非零，不据此声称整个初始化过程从未削顶。独立 SPI 检查确认 PLL 锁定、实际增益/衰减匹配、BIST/loopback/DAC test 关闭、SPI 错误数为 0。

固定版 ELF SHA-256：`2fed9cd6927a2b364217741d6a02a7219ad582735ccf01b8d7c8f9bf4c50ee06`。源码补丁、诊断头文件、链接脚本与重建入口见 [board/ldsdr](../board/ldsdr/README.md)。外部 BSP/驱动缓存仍是构建依赖；16 项离线检查及六组故障注入测试通过，重新构建的运行时 LOAD 布局和载荷校验和与实测版一致。

## UDP 回归与加载限制

固定版沿用原 UDP 解析与控制文件。遥控板通过原 `UART_NETTEST` 发送 901/1000、901/1001、900/1000 MHz 三组指令，均收到匹配 ACK，并由 LDSDR SPI 独立读回正确频率；RX I/Q 修正保持。遥控板 applied 从 10 增至 13，pending=0、failures=0。此次没有接遥控板 ADC，不能替代修改后固件的真实 ADC 自动控制回归。

原CLI的整数MHz显示有截断现象：实际PLL读回1000999998 Hz时，`status`/`lo`回复可能显示txlo=1000。本轮验收使用独立SPI的Hz值，未把该显示字段当作改频失败或精确遥测；该显示问题留待后续接口整理。

本轮早期诊断镜像暖加载后出现启动及调试访问失败，已通过一次 LDSDR 断电重启恢复。镜像 LOAD 范围与旧 ELF 的页表地址重叠，但故障前实际 TTBR 未取得，故将页表覆盖列为高风险候选原因，尚未确认根因。后续加载先检查实板 TTBR，拒绝覆盖活动页表。固定版镜像位于 `0x04000000..0x043FFFFF`，仍不能据此保证在任意旧固件上暖加载安全；重复向活动镜像自身范围下载也会被检查拒绝。

只加载了 PS 程序，没有改写 SD/Flash，也没有替换 LDSDR PL。**断电后可能重新运行旧固件，不能把当前修正当作已完成持久化部署。** 本轮结束时发送板 TX LO 关闭、DMA/DDS 关闭、两路衰减 89 dB；LDSDR mode=2、两路衰减 89 dB、RX 增益 0、900/1000 MHz；遥控板 auto/network/armed/pending 均为 0。

本轮结论限当前实物、当前频点、第一路和短时单音。调制业务数据、误码率、第二路、长时间运行及遥控与业务同时运行尚未验收。

## 天线

当前阶段全部走同轴电缆。后续若增加无线业务链路，应根据最终频率、接口及天线规格选择和验证。照片中的伸缩鞭状天线未提供型号或频段，外形不足以证明它适用于 2.4 GHz，暂不接入测试。

资料参考：[AD9363 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9363.pdf)、[ADI iio_readdev 文档](https://wiki.analog.com/resources/tools-software/linux-software/libiio/iio_readdev)。本板 Linux 驱动名称为 `ad9361-phy`，硬件身份仍以对应板卡资料为准。
