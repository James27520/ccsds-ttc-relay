# 验证记录与未完成项

记录日期：2026-10-27。对象为 Z7ADDALite 遥控板的新接收路线。下列结果来自本地开发工程及保存的测试记录；本次仅发布说明和结果摘要，新源码、原始采样文件及完整日志尚未纳入仓库。

本板实物识别和厂商资料对应 `xc7z020clg484-2`，工程基线为厂商 **LOOP**。旧交接包中的 `xc7z010clg400-1` 不适用于此板。Type-C 接 FT2232 JTAG/UART，现有资料未提供可直接使用的 PS USB Host 通路；控制转发板采用以太网。

## 已完成

### M1：125 MSPS ADC 数字接口

- AD9643 A 通道 PN9、B 通道棋盘码；SPI 配置读回正确。
- 两次临时 JTAG 加载，各采集 3 段，每段 4096 个向量、16384 个 A 样点。
- 合计 98304 个 A 样点，PN9 错误为 0；每段覆盖 511 个不同 PN9 码字、全部 14 个数据位，向量计数连续。
- 使用真实 DDR 上升沿、下降沿的最大/最小输入时序约束。PN9 诊断版 WNS=+0.483 ns、WHS=+0.075 ns，TNS=THS=0，DRC 错误为 0。
- PN9 检查按 AD9643 的每样点推进 15 bit 特性处理。测试模式的极性归一化不应用于正常 ADC 样点。

这证明当前测试条件下 ADC 数字接口、配置和样点顺序通过检查；不证明正常模拟输入、绝对采样率精度或温压全范围性能。原斜坡模式重复码现象保留记录，没有通过放宽斜坡判据将其改写为通过。

### M2：采集、缓存与 PS 接口候选

已实现 AXI-Lite 控制、只读采样 RAM、异步 FIFO、训练及模式切换、冻结/释放流程。仿真覆盖 4 个完整 131072 点快照，以及符号扩展、样点顺序、溢出、时钟停止、配置失效、取消和重新采集等场景。

候选工程布局布线报告：WNS=+0.483 ns、WHS=+0.014 ns、TNS=THS=0、DRC 错误为 0。**跨时钟握手总线目前仍有较宽泛的时序例外，需要补齐数据总线物理延迟限制并重新验收；该报告不是最终固件放行结论。** 最终源码与构建产物的一致性、匹配的位流/XSA/BSP/ELF，以及真实 ADC → RAM → PS 数据链均待上板确认。

### M3：C 协议与解调

- 数字帧和控制状态层：2906 项主机断言通过，包含三组外部金标准、极性、CRC、截断、范围、序号及 ACK 检查。
- 实数波形层：45/45 合成波形测试通过，包含频偏、相位、符号时钟偏差和负例；未将噪声、单音或坏 CRC 波形作为有效命令接受。
- 实际 Cortex-A9 上运行裸机自测：三组金标准通过；131072 点合成波形解出 rx=100 MHz、tx=2450 MHz、seq=0，串口报告 279 ms。

板载自测日志摘录：

```text
STATUS network=0 armed=0 decoded=0 applied=0 pending=0 retries=0 failures=0 gain=0 att=89
SELFTEST_PASS 3 external digital-frame vectors source=SYNTHETIC no UDP attempted
WAVEFORMTEST_PASS source=SYNTHETIC samples=131072 rx=100 tx=2450 seq=0 elapsed_ms=279 no_UDP=1
```

此次 PS 固件关闭了 ADC 采集访问，输入为合成数据，未发送 UDP。279 ms 是单块运算耗时；不能据此宣称连续实时解调 31.25 MSPS 数据流。

### M4 与上位机

26 字节 RF_SET 与旧解析器的兼容测试通过，ACK 匹配、超时、重试和冲突处理已完成软件测试。实际启用网络时，在链路未建立的条件下发现旧 lwIP 驱动协商失败进入断言、串口停止响应；修复脚本已保存，修复版尚未完成上板验收。

新串口 GUI 的 10 项模拟串口测试通过，包含参数校验、连接不自动发命令、状态和数据来源显示；未通过该 GUI 验收完整板端链路。

已验证产物及关键记录的 SHA-256 摘要见 [2026-10-27.json](validation/2026-10-27.json)。摘要用于标识已有测试版本，不替代尚未发布的源码和原始记录。所有本轮上板加载均为临时 JTAG 加载，没有写入启动 Flash。
